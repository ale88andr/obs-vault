# 04. Токены доступа

## Цель изучения
Понять, что такое access token, из чего он состоит и как используется при проверке доступа.

## Ключевые понятия

### Что такое Access Token?
**Access Token** — объект безопасности, который создаётся при входе пользователя (logon) или создании процесса. Токен представляет "личность" и "права" субъекта безопасности в данный момент.

Фактически, при проверке доступа Windows смотрит не на пользователя напрямую, а на **токен процесса**.

### Виды токенов
- **Primary Token** — основной токен процесса. Каждый процесс имеет primary token.
- **Impersonation Token** — токен, используемый потоком для временного "принятия" личности другого пользователя/контекста (имперсонация). Широко используется в клиент-серверных взаимодействиях (например, удалённый доступ).

### Состав токена
| Поле | Описание |
| --- | --- |
| **User SID** | SID пользователя, от имени которого работает субъект |
| **Group SIDs** | Список групп (включая BUILTIN\Administrators, Users, Authenticated Users и др.) |
| **Privileges** | Привилегии, доступные в этом токене (SeDebugPrivilege и др.) |
| **Integrity Level** | Уровень целостности (Low, Medium, High, System) |
| **Token Type** | Primary или Impersonation |
| **Impersonation Level** | Для impersonation-токенов (Anonymous, Identification, Impersonation, Delegation) |
| **Restricted SIDs** | Для ограниченных токенов (используется в некоторых сценариях, в т.ч. части UAC) |

### Как токен используется
1. Процесс запускается -> создаётся primary token
2. При обращении к объекту -> используется токен процесса
3. Security Reference Monitor проводит access check по токену + DACL объекта
4. Результат — разрешить/запретить доступ

- В чём разница между Primary и Impersonation токеном?
- Что входит в состав access token?
- Может ли процесс иметь разные токены у разных потоков?

## Практика
- `whoami /all` — подробно изучи вывод. Найди User, Groups, Privileges, Label (Integrity Level)
- В Process Explorer: открой свойства процесса -> Security. Там можно увидеть токен, группы, привилегии, целостность
- Сравни `whoami /all` у cmd и cmd "Run as administrator"
