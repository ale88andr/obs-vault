# 02. Процессы и потоки Windows

## Цель изучения
Научиться отличать процесс от потока, понимать дерево процессов при загрузке Windows, видеть связи родитель-потомок.

## Ключевые понятия

### Процесс vs поток
- **Процесс (Process)** — изолированный объект, содержащий виртуальное адресное пространство, исполняемый образ, дескрипторы, токен доступа и прочее.
- **Поток (Thread)** — единица исполнения внутри процесса. У процесса может быть один или несколько потоков. Потоки разделяют память процесса.

### Ключевые системные процессы (базовые)

| Процесс | Режим/Пользователь | Назначение |
| --- | --- | --- |
| **smss.exe** (Session Manager Subsystem) | SYSTEM | Первый пользовательский процесс после загрузки ядра. Создаёт сессии, запускает winlogon/csrss. |
| **csrss.exe** (Client/Server Runtime Subsystem) | SYSTEM | Поддержка Win32 подсистемы, консольные окна, обработка некоторых системных вызовов. Критичен для работы. |
| **wininit.exe** | SYSTEM | Запускается смсс. Запускает services.exe, lsass.exe, LSM (Local Session Manager). |
| **winlogon.exe** | SYSTEM | Обработка входа пользователя, загрузка профиля, запуск Userinit. |
| **services.exe** (Service Control Manager) | SYSTEM | Менеджер служб. Запускает, останавливает и управляет службами Windows. |
| **lsass.exe** (Local Security Authority Subsystem Service) | SYSTEM | Аутентификация, проверка токенов, политика безопасности, работа с LSA. Крайне важен. |
| **svchost.exe** | SYSTEM/NETWORK SERVICE/LOCAL SERVICE | Хост для служб, реализованных в DLL. Один процесс может содержать множество служб. |
| **explorer.exe** | Пользовательский | Проводник, Рабочий стол, панель задач. Запускается Userinit при входе. |

### Дерево процессов
При загрузке формируется цепочка: `System` -> `smss.exe` -> `csrss.exe`/`wininit.exe` -> `services.exe`, `lsass.exe` -> `svchost.exe` и др.

### Session 0 Isolation
С момента Vista+ все службы, не требующие интерактивного GUI, работают в Session 0. Интерактивные приложения пользователя — в его сессии. Это предотвращает взаимодействие сервисов с окнами пользователей (более безопасно).

## Практика
- В Process Explorer включи колонку `Parent` и `Session ID`. Построй цепочку загрузки для своей системы.
- В Process Explorer вкладка `Services` у svchost.exe — посмотри, какие службы в него входят.
- `tasklist /v /fi "SESSIONNAME eq Console"` — сравни с информа в Process Explorer.
