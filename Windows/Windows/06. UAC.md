# 06. UAC

## Цель изучения
Понять, зачем нужен UAC, как работает split token, elevation, consent prompt.

## Ключевые понятия

### Зачем UAC?
До Vista пользователь с правами администратора работал с **полным** административным токеном. Любое приложение, запущенное им, имело все админ-права. Это огромная поверхность атаки.

**User Account Control (UAC)** — механизм разделения полномочий. Даже если аккаунт в группе Administrators, по умолчанию он работает с **ограниченным** токеном.

### Split Token (разделённый токен)
При входе пользователя из группы Administrators создаётся **два** токена:
- **Filtered Admin Token** (урезанный) — используется по умолчанию. В нём удалены большинство административных групп и часть привилегий. Интегрити-уровень — Medium.
- **Full Admin Token** (полный) — содержит все административные группы и привилегии. Интегрити-уровень — High. Создаётся только при `elevation`.

Процесс по умолчанию получает **filtered token**.

### Elevation (повышение прав)
Когда приложение требует административных прав:
1. Пользователь запускает с `Run as administrator` или приложение запрашивает повышение (manifest `requireAdministrator`)
2. Появляется **UAC consent prompt** (запрос на согласие)
3. Если согласен и есть права — создаётся процесс с **Full Admin Token** (High Integrity)
4. Если нет прав — запрашиваются учётные данные администратора (over-the-shoulder)

### Consent Prompt (диалог UAC)
В зависимости от настроек UAC и типа учётной записи:
- **Admin approval mode** — для админов (запрос согласия)
- **Credential prompt** — для стандартных пользователей (запрос логина/пароля администратора)

### Auto-elevation
Некоторые системные исполняемые файлы из защищённых путей (`%SystemRoot%\System32\`) могут быть повышены автоматически без показа полноэкранного consent prompt (например, некоторые MMC консоли, утилиты Microsoft).

## Вопросы для самопроверки
- Почему админ-аккаунт по умолчанию не использует полные права?
- Что такое split token?
- В чём разница между filtered и full admin token?
- Что такое elevation и когда он происходит?
- Почему UAC снижает поверхность атаки?

## Практика
- Открой `cmd.exe` обычным способом и `cmd.exe` Run as administrator. Сравни `whoami /all` (группы, привилегии, Label)
- В Process Explorer сравни два cmd.exe: Integrity Level, токен
- Посмотри манифест какого-нибудь приложения: наличие `requestedExecutionLevel`
- Попробуй запустить утилиту, требующую прав, и понаблюдай за UAC prompt
