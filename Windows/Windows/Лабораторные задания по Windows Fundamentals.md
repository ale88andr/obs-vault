# Лабораторные задания по Windows Fundamentals

Цель: закрепить теорию практикой. Выполняй по порядку, фиксируй наблюдения в заметках.

## Задание 1. Карта загрузки Windows
**Цель:** Понять цепочку системных процессов

1. Открой **Process Explorer** (от имени администратора рекомендуется)
2. Включи колонки `Parent Process`, `Image Path Name`, `Session ID`
3. Найди: `System`, `smss.exe`, `csrss.exe`, `wininit.exe`, `winlogon.exe`, `services.exe`, `lsass.exe`
4. Проследи родителей для каждого
5. Зафиксируй дерево в своей заметке

**Вопросы:**
- Кто родитель `smss.exe`?
- Где больше всего создаётся `csrss.exe`? Почему?
- В каких сессиях работают wininit/winlogon?

## Задание 2. Токены в обычном и elevated окне
**Цель:** Увидеть эффект UAC

1. Открой обычный `cmd.exe`
2. Выполни: `whoami /all`
3. Открой `cmd.exe` **Run as administrator**
4. Выполни: `whoami /all`
5. Сравни:
   - User
   - Группы (особенно BUILTIN\Administrators)
   - Privileges (какие включены)
   - Mandatory Label (Integrity Level)

**Вопросы:**
- Отличается ли SID пользователя?
- Как изменилась группа Administrators?
- Какой Integrity Level в обоих случаях?

## Задание 3. Привилегии vs ACL
**Цель:** Понять разницу

1. Создай тестовый файл `C:\Temp\test_priv.txt` (создай папку C:\Temp, если нет)
2. Посмотри права через `icacls C:\Temp\test_priv.txt`
3. Попробуй запустить `whoami /all` и найди наличие `SeBackupPrivilege` и `SeDebugPrivilege`
4. В Process Explorer посмотри привилегии у `lsass.exe` (процесс находится в SYSTEM)
5. Подумай: почему lsass.exe имеет такие привилегии?

**Вопросы:**
- Что является правом доступа, а что привилегией?
- Почему системный процесс может иметь больше привилегии, чем твой админский аккаунт в обычном окне?

## Задание 4. Уровни целостности
**Цель:** Увидеть MIC на практике

1. В Process Explorer включи колонку `Integrity`
2. Найди и сравни уровни целостности для:
   - `explorer.exe`
   - `notepad.exe`
   - `cmd.exe` (обычный)
   - `cmd.exe` (Run as administrator)
   - `svchost.exe`
   - `lsass.exe`
   - `csrss.exe`

**Вопросы:**
- Какие процессы имеют High/System?
- Что будет, если низкоцелостный процесс попытается записать файл в папку с более высоким целостностью?
 - Какой уровень у обычного браузеры? (попробуй понаблюдать, если есть)
 
## Задание 5. svchost и сервисы
**Цель:** Разобраться в хостинге служб

1. В Process Explorer найдите несколько `svchost.exe`
2. Для каждого открой вкладку `Services`
3. Посмотри: какой PID, какие сервис
4. Посмотри токен/интегрити-левел
5. Почему в одного svchost не стоит объединить *все* сервис?

**Questions:**
 - Сколько сервис
 - Что происходит, если один сервис вылетает?

## Задание 6. Security Descriptor на практике
**Цель:** Осмотреть DACL/SID
1. `whoami /user` - твой SID
2. `whoami /groups` - ваши группы
3. `icacls C:\Windows\System32\config\` (обрати внимание: некоторые ключов реестра могут be small anonymous? Проверь files)
4. Найдите well-known SIDs: `S-1-5-18, S-1-5-20, S-1-5-11`
5. Проверти Link in context
**Дополнительно**: Открыть regedit (если возможности) — смотреть на HKEY_LOCAL_MACHINE\SOFTWARE качество права, но учти осторожность!

## Рекомендации

- Process Explorer лучше, but Process Monitor тоже полезен
- Если тема непонятна - обратись, объясню дополнительно
- Фиксируй резултаты in this same note or create separate ones.
