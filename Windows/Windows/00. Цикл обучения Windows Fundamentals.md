# Цикл обучения Windows Fundamentals

Цель: систематически изучить архитектуру Windows, процессы и модель безопасности. 

## План изучения

| № | Тема | Статус | Заметка |
| --- | --- | --- | --- |
| 1 | [[01. Архитектура Windows]] | К изучению | Базовое понимание устройства ОС |
| 2 | [[02. Процессы и потоки Windows]] | К изучению | Процессы, потоки, дерево загрузки |
| 3 | [[03. Основы безопасности Windows]] | К изучению | Объекты, DACL/SACL, SID |
| 4 | [[04. Токены доступа]] | К изучению | Access Tokens, состав, назначение |
| 5 | [[05. Привилегии Windows]] | К изучению | Privileges, разница с правами |
| 6 | [[06. UAC]] | К изучению | Split Token, elevation, consent |
| 7 | [[07. Уровни целостности и UIPI]] | К изучению | MIC, Integrity Levels, UIPI |

## Лабораторная работа

Смотри [[Лабораторные задания по Windows Fundamentals]] для практики к каждой теме.

## Рекомендуемый порядок

1. Начни с архитектуры, чтобы понять контекст
2. Переходи к процессам и сопоставь с [[Основные системные процессы Windows 10 и их назначение]] (если найдётся)
3. Последовательно проходи блок безопасности

## Полезные инструменты

- Process Explorer (Sysinternals)
- Process Monitor
- `whoami /all`
- `tasklist`, `taskmgr`
- `icacls` (для изучения прав)
