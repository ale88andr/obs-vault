# 03. Основы безопасности Windows

## Цель изучения
Понять объектную модель NT, как устроена проверка доступа, роль SID, DACL/SACL.

## Ключевые понятия

### Объектная модель Windows NT
В Windows почти всё — объект: файл, папка, раздел реестра, процесс, поток, событие, мутекс, сервис. У каждого объекта есть **Security Descriptor (SD)**.

### Security Descriptor (Дескриптор безопасности)
Содержит информацию для контроля доступа:
- **Owner** (Владелец) — кто может изменить дескриптор безопасности
- **Group** (Группа) — редко используется, исторический аспект
- **DACL** (Discretionary Access Control List) — список разрешений/запретов. Определяет *кто* может что делать с объектом. Именно по DACL проверяется доступ.
- **SACL** (System Access Control List) — список аудита. Определяет, какие попытки доступа логировать в журнале безопасности.

### SID (Security Identifier)
Уникальный идентификатор безопасности. Присваивается пользователю, группе, компьютеру.

Примеры well-known SIDs:
- `S-1-5-18` — Local System
- `S-1-5-19` — NT AUTHORITY\LOCAL SERVICE
- `S-1-5-20` — NT AUTHORITY\NETWORK SERVICE
- `S-1-5-32-544` — BUILTIN\Administrators
- `S-1-5-11` — Authenticated Users
- `S-1-5-7` — Anonymous Logon (позднее не всегда)

### Проверка доступа (Access Check)
Когда субъект (процесс с токеном) хочет получить доступ к объекту:
1. Берётся токен доступа субъекта (User SID, Group SIDs)
2. Смотрится DACL объекта
3. SRM (Security Reference Monitor) сравнивает SIDs из токена с ACE в DACL
4. Если есть явное `DENY` — доступ запрещён (приоритет)
5. Если есть соответствующее `ALLOW` — доступ разрешён
6. Если ничего не найден — доступ запрещён (по умолчанию)

### Принцип минимальных привилегий
Пользователь/процесс должен иметь *только* те права, которые необходим для выполнения задачи. Windows стремится придерживаться этого через токены, уровни целостности, UAC.

## Практика
- `whoami /user` — посмотри свой SID
- `whoami /groups` — посмотри группы
- Создай тестовый файл, посмотри права через `icacls <файл>`
- Найди в `icacls` SIDs/имена групп
