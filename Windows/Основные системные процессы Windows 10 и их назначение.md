# Основные системные процессы Windows 10 и их назначение

> Процесс в Windows — это не просто запущенная программа, а набор закрытого адресного пространства, данных и ресурсов, используемых при выполнении программы.

## Как просмотреть процессы

Для просмотра и управления запущенными процессами используются:

- **Диспетчер задач** — встроенный инструмент Windows 10. Процессы отображаются во вкладках «Процессы» и «Подробности».
- **Process Explorer** — более продвинутый инструмент (от Microsoft Sysinternals), позволяющий просматривать открытые дескрипторы и загруженные DLL, а также проверять файлы на VirusTotal.

## Классификация процессов в Windows 10

В Диспетчере задач все процессы делятся на три группы:

- **Приложения** — процессы штатных и сторонних прикладных программ
- **Фоновые процессы** — процессы без окон. Могут быть как системными службами, так и процессами сторонних программ (например, антивирусов)
- **Процессы Windows** — собственно процессы операционной системы, обеспечивающие её функционирование

## Основные системные процессы Windows 10

| Процесс | Расположение | Назначение | Критичность | Заметки |
| --- | --- | --- | --- | --- |
| `svchost.exe` | `C:\Windows\System32\` | Хост для служб Windows. Управляет различными службами, используя библиотеки DLL. | Критически важен | Представлен несколькими экземплярами в системе. Частая цель для вирусов. |
| `lsass.exe` | `C:\Windows\System32\` | Авторизация в системе. Инициирует запуск Проводника при успешном входе. | Критически важен | Запускается с правами SYSTEM. Частая мишень для вредоносного ПО. |
| `explorer.exe` | `C:\Windows\` | Графическая оболочка Windows, навигация по системе. | Важен для GUI | Отключение не завершит работу системы, но сделает GUI недоступным. Может иметь несколько экземпляров. |
| `sihost.exe` | `C:\Windows\System32\` | Обслуживание инфраструктуры оболочки. Участие в работе Центра действий, меню Пуск. | Важен | Системный хост-процесс. |
| `ntoskrnl.exe` / `System` | `C:\Windows\System32\` | Ядро операционной системы. Обеспечивает работу множества системных функций и драйверов. | Критически важен | Завершение невозможно, без него система не работает. |
| `wininit.exe` | `C:\Windows\System32\` | Управляет автозагрузкой. Запускает службы SCM, LSASS, LSM (диспетчер управления службами). | Критически важен | Случаи подмены вирусом не замечены. |
| `dwm.exe` (Диспетчер окон рабочего стола) | `C:\Windows\System32\` | Управляет визуальными эффектами: окна, меню, рабочий стол. | Важен | Вероятность заражения невелика. |
| `smss.exe` (Session Manager Subsystem) | `C:\Windows\System32\` | Управляет сеансом авторизованного пользователя. Инициирует запуск Winlogon и Win32. Участвует в установке системных переменных. | Критически важен | Высокая вероятность заражения при подмене. |
| `services.exe` | `C:\Windows\System32\` | Управление системными службами. | Критически важен | При запуске под другим пользователем — вероятно заражение/подмена. |
| `winlogon.exe` | `C:\Windows\System32\` | Авторизация и выход пользователя из системы. | Критически важен | Заражения встречаются нечасто. |
| `csrss.exe` (Client Server Runtime Process) | `C:\Windows\System32\` | Управляет консольными приложениями (командная строка), компонент клиент-сервер. | Критически важен | Высокая вероятность заражения при подмене. |

## Основные фоновые системные процессы

| Процесс | Расположение | Назначение | Критичность | Заметки |
| --- | --- | --- | --- | --- |
| `RuntimeBroker.exe` | `C:\Windows\System32\` | Управление разрешениями универсальных приложений UWP (доступ к камере, микрофону и др.). | Важен | Для каждого запущенного UWP-приложения может быть свой экземпляр. |
| `ApplicationFrameHost.exe` | `C:\Windows\System32\` | Обеспечивает запуск универсальных приложений UWP в окнах. | Важен | Принудительное завершение закроет все запущенные UWP-приложения, включая работающие в фоне. |
| `ctfmon.exe` | `C:\Windows\System32\` | Работа языковой панели, управление вводом данных. | Не критичен | При завершении обычно перезапускается автоматически. |
| `SecurityHealthService.exe` | `C:\Windows\System32\` | Работа Центра безопасности Windows 10. | Важен | Управляется системой, завершение через Диспетчер задач не предусмотрено. |
| `spoolsv.exe` (Print Spooler) | `C:\Windows\System32\` | Обеспечивает вывод на печать принтеров и периферийных устройств печати. | Не критичен | Может быть завершён через Диспетчер задач или отключён в службах. |

## Советы по безопасности

- **Проверяйте расположение**. Большинство подлинных системных процессов находятся в `C:\Windows\System32\`. Процессы, запущенные из папок пользователя, часто вызывают подозрения.
- **Используйте дополнительные инструменты**. Если есть сомнения в подлинности процесса, можно проверить его через Process Explorer с интеграцией VirusTotal.
- **Не пугайтесь неизвестных процессов**. Помимо перечисленных, в системе могут работать процессы драйверов устройств и дополнительных компонентов, что является нормальным явлением.
