### 2. Kaspersky Security Center — практика

- [[KSC]] — справочник: компоненты, пути установки, службы и учётные записи (KL-AK-*, KIScSvc), порты, ключи vs коды активации, стандартные задачи сервера, три способа опроса сети (быстрый/полный Windows, Active Directory, IP-подсети), инсталляционные пакеты, обзор линейки EPP (KESS для embedded, KSWS для серверов).
- [[Развертывание Kaspersky Security Center]] — пошаговое развёртывание **KSC на Astra Linux**: подключение репозитория astra-ce, PostgreSQL 14 с тюнингом postgresql.conf, создание пользователя kscadmin/kscdb, postinstall.pl, файл ответов для Web Console, сравнение KSC Linux vs Windows.
- [[Установка klnagent]] — подготовка Astra Linux к удалённой установке (PATH в .bashrc, KillUserProcesses=no, NOPASSWD в sudoers) + проверка портов через `nc`.
- [[Пример политики KSC]] — визуальная инструкция из ~60 скриншотов настроек политики, практически без текста.
- [[Рекомендации по ежедневному администрированию Kaspersky Security Center]] — операционный runbook: ежедневные отчёты и виджеты, диагностика статусов защиты, удалённый запуск KES, утилиты klnagchk/klmover, работа с лицензиями и резервными ключами, периодический чеклист, чеклист при инциденте, лечение активного заражения.
- [[Ошибка - Содержимое не готово]] — точечный фикс: очистка хранилища обновлений → перезапуск kladminserver → повторная загрузка.

### 3. Управление защитой (конспекты)

- [[KSC Защита]] — ядро базы знаний: все пути проникновения ВПО (браузер, почта, флешки/BadUSB, сеть) и контрмеры к каждому; детальная настройка Защиты от файловых угроз (klif.sys, NTFS vs FAT32, архивы, офисные форматы); SSL/TLS-инспекция через подмену сертификата; почтовые/веб-угрозы; продвинутая защита (Анализ поведения, Откат, Предотвращение вторжений с группами доверия, эксплойты, AMSI); пакетные правила сетевого экрана; автономные политики для ноутбуков вне офиса; самозащита и парольная защита.
- [[KSC Контроль программ]] — запрещающий vs разрешающий режим контроля запуска.
- [[KSC Обслуживание]] — регламент по периодам (день/неделя/месяц/квартал/год), панель мониторинга, критичные события, план реагирования на заражение, резервное копирование через klbackup, обслуживание БД.
