## Что бы я добавил по существу

**1. Отсутствующие классы сетевых атак** — минимум списком, часть уже покрыта вашими заметками:
- **MITM / on-path** — у вас есть целая заметка [[Атака Man-In-The-Middle]], но здесь она даже не упомянута;
- **Сниффинг** (пассивный перехват трафика);
- **DNS-спуфинг / отравление кэша** — есть заметка [[DNS Спуфинг]];
- **Session hijacking** (угон сессии через кражу cookies — сейчас это главный обход MFA);
- **IP-спуфинг**, reflection/amplification DDoS (DNS-, NTP-, memcached-амплификация — рекорд 1.7 Тбит/с ещё в 2018);
- **Социальная инженерия шире фишинга**: spear phishing, whaling, BEC, vishing/smishing, а с 2024+ — голосовые дипфейки.

**2. Уточнения по DDoS.** Сейчас описана только объёмная атака (L3/L4). Стоило бы добавить прикладной уровень (**L7 DDoS** — HTTP-flood, который не видно по битрейту) и связь с триадой CIA: DoS бьёт по доступности — у вас же есть заметка [[CIA]].

**3. Фактические неточности:**
- *«Всю эту гадость принято объединять одним определением — Троян»* — **неверно**. Троян — это механизм доставки (маскировка под легитимное ПО), а не общий термин. Бэкдор и руткит троянскими быть не обязаны. Общий термин — просто «вредоносное ПО» (malware).
- WannaCry стоит дополнить: он распространялся через эксплойт **EternalBlue** (CVE-2017-0144, MS17-010) против SMBv1 — и это гибрид «червь + шифровальщик», что само по себе показательный кейс.
- Пример с Necurs устарел (ботнет демонтирован Microsoft в 2020). Свежее — Mirai и его наследники для IoT, ботнеты типа Mozi.
- Про ransomware пропущена современная реальность: **double extortion** (шифрование + кража данных с угрозой публикации), **RaaS** (ransomware-as-a-service) и аукционы первичного доступа. Шифровальщик без экзфильтрации сегодня — редкость.

**4. Раздел про brute force — самый слабый.** Нет различия между:
- полным перебором, **атакой по словарю** и **credential stuffing** (подбор по слитым базам — сейчас доминирующий сценарий);
- защитой: rate limiting, блокировка аккаунта, CAPTCHA и главное — **MFA**. И совет «используйте генератор паролей» стоит заменить на принцип NIST: длина важнее сложности, парольные фразы, менеджер паролей, уникальность пароля на каждый сервис.
