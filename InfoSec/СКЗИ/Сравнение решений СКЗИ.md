# Сравнение решений СКЗИ

Обзор основных производителей средств криптографической защиты информации, сертифицированных ФСБ России.

## Криптопровайдеры (программные СКЗИ)

Программные средства, реализующие криптографические алгоритмы. Используются как базовый компонент для построения защищённых систем.

| ----------------- | ---------------------- | --------------------------------------------------- | ------------------------------ | ---------- | ---------------------------------------------------------------------- |
| **КриптоПро CSP** | КриптоПро              | ГОСТ 28147-89, ГОСТ Р 34.10-2012, ГОСТ Р 34.11-2012 | Windows, Linux, macOS, FreeBSD | КС1        | Наиболее распространённый в России. Поддержка CryptoAPI, CNG, PKCS#11. |
| **ViPNet CSP**    | ИнфоТеКС               | ГОСТ 28147-89, ГОСТ Р 34.10-2012, ГОСТ Р 34.11-2012 | Windows, Linux                 | КС1        | Интеграция с экосистемой ViPNet (VPN, почта, файловое шифрование).     |
| **С-Терра CSP**   | С-Терра                | ГОСТ 28147-89, ГОСТ Р 34.10-2012, ГОСТ Р 34.11-2012 | Windows, Linux                 | КС1        | Ориентация на TLS/VPN решения.                                         |
| **ЛЭТИ-Крипто**   | ЛЭТИ (ЦНИИ «Прогресс») | ГОСТ 28147-89, ГОСТ Р 34.10-2012, ГОСТ Р 34.11-2012 | Windows, Linux                 | КС1        | Разработка на базе лаборатории электротехники.                         |

## Сравнение по классам СКЗИ

| Класс | Минимальные решения | Рекомендуемые решения |
| --- | --- | --- |
| **КС1** | КриптоПро CSP + стандартная ОС | ViPNet Client / Coordinator (программная версия) |
| **КС2** | ViPNet Coordinator HW (базовая модель) + АПМДЗ | ViPNet Coordinator HW 2000 + Astra Linux SE |
| **КС3** | ViPNet Coordinator HW + АПМДЗ + замкнутая среда | ViPNet Coordinator HW 5000 + Astra Linux SE (макс. доверие) |
| **КВ** | Специализированные комплексы с защитой от ПЭМИН | ViPNet Coordinator KB + экраны + клетки Фарадея |
| **КА** | Специализированные аппаратные решения | Индивидуальные проекты с учётом требований ФСБ |

## Экосистема производителей

### ИнфоТеКС (ViPNet)
- Полный стек: криптопровайдер, VPN, почта, IDS, NGFW
- Собственный проприетарный протокол (не IPsec)
- Централизованное управление через ViPNet Administrator
- Подробнее: [[Технология ViPNet]]

### КриптоТЭК / КриптоПро
- Наибольшее распространение криптопровайдера в России
- Стандарт de facto для ЭП и шифрования
- Широкая совместимость с продуктами других вендоров

### С-Терра
- Фокус на VPN и межсетевом экранировании
- Стандартный IPsec — хорошая совместимость
- Решения для ГосСОПКА и КИИ

### Astra Linux (РусБИТех)
- Операционная система — основа замкнутой среды
- Мандатный контроль доступа (МКЦ)
- Режим максимального уровня доверия для КС3+

## Критерии выбора

При выборе решения СКЗИ учитывайте:

- **Класс защиты** — определён по [[Выбор класса СКЗИ — чеклист]]
- **Совместимость** — интеграция с имеющейся инфраструктурой (ОС, сеть, приложения)
- **Пропускная способность** — для VPN-шлюзов критична производительность шифрования
- **Стоимость** — лицензии на ПО + аппаратура + обслуживание
- **Поддержка** — наличие сервисных контрактов и квалифицированной техподдержки
- **Сертификация** — действующий сертификат ФСБ нужного класса
- **Производительность** — аппаратная реализация (АПК) vs программная
