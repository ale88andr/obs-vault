# Этап 10 — Практика и закрепление

> [!todo] Приоритет: КРИТИЧЕСКИЙ (параллельно с каждым этапом)
> NAD осваивается только на трафике: детект без возможности поднять PCAP — это гипотеза, а не навык.

---

## 10.1 Лабораторная среда

Минимальная схема:
- источник трафика (интернет + имитация внутренних сегментов)
- PT NAD (демо-среда, лаборатория или курс Positive Education)
- точка перехвата: SPAN/TAP на периметре, при возможности — зеркало внутреннего сегмента
- «жертвы»: 2–3 виртуальные машины (Windows-клиент, Linux-сервер, веб-сервер)

## 10.2 Генерация трафика для проверки детектов

| Упраждение | Инструменты (примеры) | Что должно появиться |
| --- | --- | --- |
| Сканирование портов | nmap | атака/активность «сканирование», сессии в одной записи |
| Медленное сканирование | nmap с задержками | улучшенное в 12.3 правило «Медленное сканирование» |
| Перебор учётных данных | hydra, медленный RDP/SMB | активности брутфорса, `credentials.*` |
| Веб-атака | SQLi-запросы, web-шелл | атаки веб-класса, Payload в карточке |
| Заражённый файл | передача EICAR, test-PE | `files.*`, вердикт MultiScanner/Sandbox |
| DNS-туннель | dnscat, iodine | активность «DNS-туннелирование» (правило улучшено в 12.3) |
| ICMP-туннель | ptunnel | детект туннелирования (приложение Г) |
| DGA-домены | генератор случайных доменов | IOC `rpt.color == 8`, исключения DGA |
| DDoS/флуд | hping3, flood | срабатывание самозащиты/правил флуда |
| Эксплуатация уязвимости | Metasploit в лабе | атака с описанием и рекомендациями |

После каждого упражнения пройти путь до конца: **атака/активность → сессия → Payload/файл → фильтр → отчёт**.

## 10.3 Чек-лист практических навыков

### Основной уровень
- [ ] Вход в интерфейс, навигация по всем разделам главного меню
- [ ] Написание фильтров: 20+ параметров, `and/or/not`, `in [..]`, `~`, полнотекстовый поиск
- [ ] Карточка сессии: расширенные данные, флаги/ошибки, DGA, файлы, IOC
- [ ] Экспорт PCAP и метаданных, скачивание файла из сессии
- [ ] Карточка атаки: описание, ATT&CK, правило, Payload
- [ ] Отметка о ложном срабатывании + исключение в справочник
- [ ] Лента активностей: просмотр → дашборд → решение → комментарий
- [ ] Выпуск отчёта вручную и настройка автотчета
- [ ] Регистрация инцидента в MaxPatrol 10

### Продвинутый уровень
- [ ] Фильтр захвата BPF на модуле ptdpi (создание/изменение), понимание влияния на производительность
- [ ] Написание пользовательского правила для атаки (приложение Ж, `ptrule`)
- [ ] Настройка обучения правила профилирования + перезапуск обучения
- [ ] Группы узлов и портов для корректной работы правил
- [ ] Иерархия «центральная консоль — дочерние системы» (включая операции 12.3)
- [ ] Работа с репутационными списками, исключениями DGA
- [ ] Плейбуки: применение при реагировании на инцидент
- [ ] REST API: выгрузка данных за период

## 10.4 Курс и сертификация

- Курс Positive Technologies по PT NAD — **требование раздела 4** руководства (обучение работе с продуктом и администрированию СЗИ); проверить актуальное название и расписание на [edu.ptsecurity.com](https://edu.ptsecurity.com/)
- Руководство оператора читать параллельно как справочник: [[attachments/nad_12.3_operator.pdf|Руководство оператора PT NAD 12.3]]
- Руководство администратора — для понимания мониторинга, ротации и квот
- Портал технической поддержки (раздел 1.2 руководства) — база знаний, новости обновлений, FAQ

## 10.5 Итоговая работа (защита)

Составить досье по одному сгенерированному в лабе инциденту:
1. Какой детект сработал (правило/активность, версия, источник)
2. Цепочка: фильтр → сессии → карточка атаки/активности
3. Артефакты: PCAP, файл с MD5, домены/IP, Payload
4. Затронутые узлы и сетевые связи
5. Ложные срабатывания и как подавлялись
6. Отчёт PDF/DOCX + регистрация инцидента в MaxPatrol 10
7. Рекомендации: что чинить в инфраструктуре, а что — в правилах
