Вы можете приостанавливать задачи, например чтобы снизить нагрузку на оборудование в сети. В систему будут загружены результаты тех подзадач, которые успели завершиться до момента приостановки. При повторном запуске сканирование продолжится только для непросканированных активов, результаты успешно выполненных подзадач сканирования для этих активов так же будут загружены в систему.

**Задача.** Чтобы приостановить задачу:

1. В главном меню выберите **Сбор данных** → **Задачи**.
   → Откроется страница **Задачи по сбору данных**.
2. В панели **Все задачи** выберите задачу.
   > [!note] Примечание
   > Для выбора нескольких задач подряд вы можете использовать клавишу Shift, для выбора нескольких отдельных задач — клавишу Ctrl, для выбора всех задач в списке — комбинацию клавиш Ctrl+A.
3. В панели инструментов нажмите кнопку **Пауза**.

> Задача приостановлена.
