Вы можете останавливать задачи, например чтобы снизить нагрузку на оборудование в сети. В систему будут загружены только результаты завершенных подзадач сканирования. При повторном запуске для всех активов сканирование начнется сначала.

**Задача.** Чтобы остановить задачу:

1. В главном меню выберите **Сбор данных** → **Задачи**.
   → Откроется страница **Задачи по сбору данных**.
2. В панели **Все задачи** выберите задачу.
   > [!note] Примечание
   > Для выбора нескольких задач подряд вы можете использовать клавишу Shift, для выбора нескольких отдельных задач — клавишу Ctrl, для выбора всех задач в списке — комбинацию клавиш Ctrl+A.
3. В панели инструментов нажмите кнопку **Остановить**.

> Задача остановлена.
