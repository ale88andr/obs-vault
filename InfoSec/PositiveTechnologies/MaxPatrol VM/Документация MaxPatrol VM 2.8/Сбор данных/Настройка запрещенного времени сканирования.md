# Настройка запрещенного времени сканирования

Сканирование может нагружать целевые активы, замедляя выполнение их основных задач. Вы можете настроить запрещенное время для задач сканирования. Как только оно начнется, сбор данных будет приостановлен, в систему будут загружены результаты только завершенных подзадач сканирования. Когда запрещенное время закончится, сбор данных будет автоматически возобновлен.

**Задача.** Чтобы настроить запрещенное время сканирования:

1. В главном меню выберите **Сбор данных** → **Задачи**.
   → Откроется страница **Задачи по сбору данных**.
2. В панели **Все задачи** выберите задачу на сканирование.
3. В панели инструментов нажмите кнопку **Изменить**.
   → Откроется страница **Задачи / <Название задачи>**.
4. Включите запрещенное время сканирования.
5. Добавьте запрещенные интервалы.
   > [!warning] Внимание
   > Не следует объединять в один интервал дни, которые идут друг за другом. Например, вместо интервала «Суббота, воскресенье, весь день» необходимо выбрать два интервала: «Суббота, весь день» и «Воскресенье, весь день».
6. Нажмите **Сохранить**.

> Запрещенное время настроено.
