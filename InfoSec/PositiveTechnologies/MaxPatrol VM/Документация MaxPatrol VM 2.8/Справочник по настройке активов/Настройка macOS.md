Для настройки macOS необходимо настроить (создать) домашний каталог.

## Настройка пути к домашнему каталогу

Если параметр привязки к домену **Обязательно использовать папку пользователя на загрузочном диске** включен, то домашним каталогом пользователя является `/Users/<Имя пользователя>` (например, домашним каталогом для пользователя username@domain.ru в этом случае будет `/Users/username`). Вы можете проверить, включен ли параметр, выполнив команду `dsconfigad -show | grep -i "Force home"`. Вы также можете открыть приложение **Служба каталогов**, выбрать **Службы** → **Active Directory** → **Показать параметры** и проверить, включен ли параметр **Обязательно использовать папку пользователя на загрузочном диске**. Если параметр выключен, нужно [[Настройка SSSD|настроить путь к каталогу в Active Directory]].

## Создание домашнего каталога

**Задача.** Чтобы создать домашний каталог:

1. Выполните команду:
   ```
   dscl "/Active Directory/<NetBIOS-имя домена>/<DNS-имя домена>" read /Users/<Имя пользователя> NFSHomeDirectory
   ```
   → В результате будет получен путь к домашнему каталогу пользователя.
2. Выполните команды:
   ```bash
   mkdir <Путь к каталогу>
   chown <Имя пользователя>:<Название группы>
   ```

## Используемая командная оболочка

Если путь к командной оболочке для пользователя [[Настройка SSSD|указан в Active Directory с помощью параметра loginShell]], то используется командная оболочка из значения этого параметра. Если значение параметра `loginShell` пусто, то используется командная оболочка, заданная по умолчанию. Вы можете просмотреть, какая оболочка задана по умолчанию, выполнив команду `dsconfigad -show | grep -i "Default user Shell"`.

Вы можете проверить, задана ли оболочка по умолчанию, с помощью графического интерфейса. Для этого нужно открыть приложение **Служба каталогов** и выбрать **Службы** → **Active Directory** → **Показать параметры**. Если включен параметр **Shell пользователя по умолчанию** и указан путь к командной оболочке, то оболочка, используемая по умолчанию, задана.

Вы можете проверить, какая командная оболочка назначена тому или иному пользователю, с помощью команды `dscl "/Active Directory/<NetBIOS-имя домена>/<DNS-имя домена>" read /Users/<Имя пользователя> UserShell`.
