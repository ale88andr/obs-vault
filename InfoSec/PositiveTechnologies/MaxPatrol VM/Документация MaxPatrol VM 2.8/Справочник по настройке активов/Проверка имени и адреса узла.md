# Проверка имени и адреса узла

Одной из причин ошибки «0x800706ba (RPC Server is unavailable)» может быть неверная запись имени или адреса сканируемого узла на DNS-сервере или несовпадение с настоящими именем или адресом.

**Задача.** Чтобы проверить имя и адрес узла:

1. С помощью командной строки Windows запустите утилиту `wbemtest`.
   → Откроется окно **Тестер инструментария управления Windows**.
2. Нажмите **Подключить**.
   → Откроется окно **Подключение**.
3. В блоке параметров **Учетные данные** введите верное имя пользователя и неверный пароль и нажмите **Подключить**.
   → Если возникла ошибка «0x80070005 (Access Denied)», проблема с прямым или обратным запросом имени узла.
   > [!note] Примечание
   > Повторное возникновение ошибки «0x800706ba (RPC Server is unavailable)» может означать некорректный ввод имени учетной записи.
4. Запустите интерпретатор командной строки `cmd.exe`.
5. Выполните команду `ipconfig /all` и просмотрите имя и IP-адрес сканируемого узла.
6. Выполните команду `ping <имя_узла>` и проверьте, совпадает ли полученный IP-адрес с настоящим.
7. Выполните команду `nslookup <IP_адрес>` и проверьте, совпадает ли полученное имя узла с настоящим.

> Имя и адрес узла проверены.

Если при проверке выявлены расхождения, обратитесь к системному администратору.
