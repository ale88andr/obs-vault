> [!warning] Внимание
> Для проведения аудита актива по протоколу SSH используется порт TCP 22.

Для проведения аудита на активе нужно настроить [ОС для аудита](https://help.ptsecurity.com/ru-RU/projects/vm/2.8/help/903658635).
