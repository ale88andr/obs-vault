**Задача.** Чтобы настроить сетевой доступ:

1. В командной строке Windows выполните команду `mmc`.
   → Откроется окно **Консоль1**.
   ![[760217995.png]]

   *Главное окно Microsoft Management Console*
2. Нажмите комбинацию клавиш Ctrl+M.
   → Откроется окно **Добавление и удаление оснасток**.
3. В списке доступных оснасток выберите **Редактор объектов групповой политики** и нажмите **Добавить**.
   → Откроется окно **Выбор объекта групповой политики**.
4. Нажмите **Готово**.
5. В окне **Добавление и удаление оснасток** нажмите **ОК**.
   ![[760219915.png]]

   *Сохранение настроек*
6. В иерархическом списке выберите папку **Политика «Локальный компьютер»** → **Конфигурация компьютера** → **Конфигурация Windows** → **Параметры безопасности** → **Локальные политики** → **Параметры безопасности**.
7. В правой области выберите политику **Сетевой доступ: модель общего доступа и безопасности для локальных учетных записей**.
   ![[760221835.png]]

   *Выбор политики*
8. С помощью контекстного меню откройте свойства политики и убедитесь, что выбрано значение **Обычная: локальные пользователи удостоверяются как они сами**.

> Настройка сетевого доступа выполнена.
