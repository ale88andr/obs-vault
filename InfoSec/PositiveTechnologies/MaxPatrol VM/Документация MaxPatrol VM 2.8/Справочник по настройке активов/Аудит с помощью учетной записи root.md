> [!warning] Внимание
> Аудит с использованием учетной записи root считается небезопасным, поскольку эта учетная запись предоставляет полный доступ к системе.

> [!note] Примечание
> В macOS учетная запись root по умолчанию отключена. Для ее включения необходимо от имени пользователя, состоящего в группе администраторов, выполнить команду `dsenableroot`.

## Настройка актива

**Задача.** Чтобы настроить актив:

1. Откройте файл конфигурации `/etc/ssh/sshd_config`.
   > [!note] Примечание
   > В операционной системе «Альт» файл находится по пути`/etc/openssh/sshd_config`.
2. Добавьте в файл строку:
   ```
   PermitRootLogin yes
   ```
3. Сохраните изменения и закройте файл.

> [!note] Примечание
> Для используемой учетной записи root в операционной системе Astra Linux Special Edition нужно дополнительно [[Настройка уровня целостности для учетной записи в Astra Linux Special Edition|настроить уровень целостности]].
