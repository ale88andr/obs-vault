**Задача.** Чтобы определить используемую на источнике службу журналирования,

1. выполните команду:
   - если установлена операционная система «Альт»:
   ```
   rpm -qa | grep syslog
   ```
   - если Astra Linux, Debian или Ubuntu:
   ```
   dpkg --list | grep syslog
   ```
   - если CentOS, Platform V SberLinux OS Server, Oracle Linux, Red Hat Enterprise Linux или «РЕД ОС»:
   ```
   rpm -qa *syslog*
   ```
   - если SUSE Linux Enterprise Server:
   ```
   zypper search *syslog* --installed-only | grep 'i |'
   ```
   → На экране появится название используемой службы.
