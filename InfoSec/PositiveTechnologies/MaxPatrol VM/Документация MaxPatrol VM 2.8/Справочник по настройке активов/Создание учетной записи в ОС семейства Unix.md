> [!warning] Внимание
> Процедуру создания учетной записи нужно выполнять от имени учетной записи root.

**Задача.** Чтобы создать и настроить учетную запись:

1. Создайте учетную запись для нового пользователя, выполнив следующие команды (в зависимости от дистрибутива):
   - FreeBSD:
   ```
   adduser
   ```
   → После выполнения команды нужно указать данные нового пользователя:
   ```
   Login: <Логин>
   Shell: sh
   Password: empty - no, random - no
   <Пароль>
   ```
   - Oracle Solaris:
   ```
   useradd -m <Логин>
   passwd <Логин>
   ```
   → После выполнения команд нужно указать пароль для нового пользователя.
   - IBM AIX:
   ```
   useradd -m -s /bin/sh <Логин>
   echo '<Логин>:<Пароль>' | chpasswd
   pwdadm -c <Логин>
   ```
   - HPE HP-UX:
   ```
   useradd -m -g users -s /bin/sh <Логин>
   passwd <Логин>
   ```
   → После выполнения команд нужно указать пароль для нового пользователя.
   - macOS:
   ```
   Sysadminctl -addUser <Логин> -shell /bin/bash
   passwd <Логин>
   ```
   - Другая ОС:
   ```
   useradd -m -g users -s /bin/bash <Логин>
   passwd <Логин>
   ```
   → После выполнения команд нужно указать пароль для нового пользователя.
2. Настройте права доступа к домашнему каталогу:
   - Oracle Solaris:
   ```bash
   chmod 700 /export/home/<Логин>
   ```
   - Другая ОС:
   ```bash
   chmod 700 /home/<Логин>
   ```
3. Войдите в систему от имени созданной учетной записи, чтобы проверить корректность выполненной настройки:
   ```
   su - <Логин>
   <Пароль>
   ```

> [!note] Примечание
> В macOS вы также можете создать учетную запись с помощью графического интерфейса. Для этого необходимо открыть приложение **Системные настройки**, выбрать **Пользователи и группы** → **Добавить пользователя**, ввести имя, логин и пароль учетной записи и нажать **Создать пользователя**.
