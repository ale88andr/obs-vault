# Настройка доступа к портам

Для сканирования удаленного компьютера системе Positive Technologies MaxPatrol VM требуется доступ к определенным сетевым портам. Параметры портов должны удовлетворять следующим требованиям:

- Порты 135 и 445 на удаленном узле прослушиваются. Для проверки необходимо в командной строке выполнить команду `netstat -a -n`.
- Доступ к портам 135 и 445 сканируемого узла разрешен. Вы можете проверить наличие доступа к портам с помощью клиента Telnet, запущенного на сканирующем узле. Если доступ к портам отсутствует, проверьте параметры межсетевого экрана на сканируемом и (или) промежуточном узле на наличие правил, блокирующих трафик.
- Доступ к динамическим портам сканируемого узла разрешен. Диапазон динамических портов вы можете просмотреть на сайте [support.microsoft.com](https://support.microsoft.com/help/832017/service-overview-and-network-port-requirements-for-windows).

Если политика безопасности не позволит применить диапазон, вы можете настроить работу DCOM на другой диапазон и разрешить трафик по нему на межсетевом экране.

**Задача.** Чтобы настроить работу DCOM на другой диапазон:

1. С помощью командной строки Windows запустите утилиту dcomcnfg.
2. В иерархическом списке выберите **Службы компонентов** → **Компьютеры** → **Мой компьютер** и с помощью контекстного меню откройте свойства.
   → Откроется окно **Службы компонентов**.
3. Выберите вкладку **Набор протоколов** и нажмите **Свойства**.
   → Откроется окно **Свойства Интернет**-**служб COM**.
4. Нажмите **Добавить**.
   → Откроется окно **Добавление диапазона портов**.
   ![[760212235.jpg]]

   *Добавление диапазона портов*
5. В поле **Диапазон портов** укажите интервал.
6. Нажмите **ОК**.
7. Перезагрузите узел.

> Работа DCOM настроена на другой диапазон.
