**Задача.** Чтобы настроить удаленный доступ для учетной записи, от имени которой выполняется сканирование:

1. С помощью командной строки Windows запустите утилиту dcomcnfg.
   → Откроется окно **Службы компонентов**.
2. В иерархическом списке выберите **Службы компонентов** → **Компьютеры** → **Мой компьютер** и с помощью контекстного меню откройте свойства.
   → Откроется окно **Свойства: Мой компьютер**.
3. Выберите вкладку **Безопасность COM**.
   ![[760210315.png]]

   *Настройка безопасности COM*
4. В блоке параметров **Права доступа** нажмите **Изменить ограничения**.
   → Откроется окно **Разрешение на доступ**.
5. Установите флажок **Удаленный доступ**.
6. Нажмите **ОК**.
   ![[790931083.png]]

   *Изменение прав доступа*
7. В блоке параметров **Разрешения на запуск и активацию** нажмите **Изменить ограничения**.
8. Установите флажки **Локальный запуск** и **Удаленная активация**.
9. Нажмите **ОК**.

> Удаленный доступ для учетной записи настроен.
