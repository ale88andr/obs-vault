> [!warning] Внимание
> На активе должна быть установлена программа sudo.

## Настройка актива

**Задача.** Чтобы настроить актив:

1. Если требуется, [[Создание учетной записи в ОС семейства Unix|создайте учетную запись для доступа к активу]].
2. Выполните команду:
   ```
   visudo
   ```
3. Добавьте в конфигурационный файл строку:
   ```xml
   <Логин учетной записи> ALL=(ALL) ALL
   ```
4. Сохраните изменения и закройте файл.

При проведении аудита с помощью доменной учетной записи:

- для входа на актив с macOS нужно указать имя пользователя;
- для входа на актив с другой ОС при использовании SSSD нужно указать доменное имя пользователя;
- для входа на актив с другой ОС при использовании Winbind, если в файле конфигурации `/etc/samba/smb.conf` параметр `winbind use default domain` установлен в значение `yes`, то нужно указать имя пользователя; если параметр установлен в значение `no` или отсутствует, то нужно указать доменное имя пользователя.

> [!note] Примечание
> Для используемой учетной записи в операционной системе Astra Linux Special Edition нужно дополнительно [[Настройка уровня целостности для учетной записи в Astra Linux Special Edition|настроить уровень целостности]].

> [!note] Примечание
> Для команды sudo в операционной системе «Альт» нужно дополнительно [[Настройка политики control для команд su и sudo в операционной системе «Альт»|настроить политику control]].
