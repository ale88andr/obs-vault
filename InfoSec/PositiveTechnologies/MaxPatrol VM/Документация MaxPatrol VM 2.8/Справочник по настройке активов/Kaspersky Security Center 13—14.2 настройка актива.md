Настройку актива нужно выполнять в Kaspersky Security Center Web Console или в консоли управления Kaspersky Security Center для ОС Windows от имени учетной записи с ролью «Главный администратор».

Инструкции по настройке и установке см. на сайте [kaspersky.ru](https://www.kaspersky.ru/).

Для аудита актива нужно:

1. На сервере Kaspersky Security Center необходимо разрешить доступ к порту TCP/13299 для сбора данных
2. Создать учетную запись для доступа MP 10 Collector к активу через веб-API.
3. Создать и настроить роль для учетной записи.
4. Назначить созданную роль учетной записи.

## Настройка через Kaspersky Security Center (Windows)

**Задача.** Чтобы создать и настроить учетную запись для доступа к активу:

1. Запустите приложение Kaspersky Security Center.
2. В списке выберите нужный сервер администрирования, нажмите правой кнопкой мыши на выбранный сервер и в контекстном меню выберите **Properties**.
   → Откроется окно **Свойства**.
3. В разделе **Роли пользователей** нажмите **Добавить…**
4. В открывшемся окне в разделе **Общие** введите имя новой роли (например, **Аудит MPX**).
5. В разделе **Права** перейдите в **Сервер администрирования Kaspersky Security Center** → **Общий функционал** → **Базовая функциональность** → **Чтение** и установите флажок **Разрешить**, нажмите **ОК**.
6. В разделе **Безопасность** нажмите **Внутренний пользователь**.
7. В открывшемся окне **Выбор пользователя** нажмите **Добавить пользователя…**.
8. В открывшемся окне **Новый пользователь** введите имя учетной записи (например, **mpaudit**) и пароль для новой учетной записи, нажмите **ОК**.
9. В окне **Выбор пользователя** выберите имя созданной на предыдущем шаге учетной записи, нажмите **ОК**.
   → Учетная запись появится в списке учетных записей в разделе **Безопасность**.
10. Выберите имя учетной записи в списке, в разделе **Разрешения** выберите вкладку **Роли** и нажмите **Добавить…**.
11. В открывшемся окне **Роли пользователей** выберите роль, созданную ранее, и нажмите **ОК**.
12. В окне **Свойства** нажмите **Применить**, затем **ОК**.

## Настройка через Kaspersky Security Center Web Console

**Задача.** Чтобы создать и настроить учетную запись для доступа к активу:

1. Запустите Kaspersky Security Center Web Console.
2. Войдите на сервер администрирования от имени учетной записи с ролью «Главный администратор».
3. На главной странице выберите **Пользователи и роли** → **Пользователи**.
4. Нажмите **Добавить**.
5. Выберите тип учетной записи **Пользователь**.
6. Введите логин учетной записи.
7. Введите пароль учетной записи.
8. Нажмите **ОК**.
9. На главной странице выберите **Пользователи и роли** → **Роли**.
10. Нажмите **Добавить**.
11. Введите название роли.
12. Нажмите **ОК**.
13. Выберите вкладку **Права доступа**.
14. В иерархическом списке выберите **Сервер администрирования** → **Общий функционал** → **Базовая функциональность**.
15. Установите флажок **Чтение**.
16. Нажмите **Сохранить**.
17. На главной странице выберите **Пользователи и роли** → **Пользователи и группы**.
18. Выберите вкладку **Пользователи**.
19. Выберите учетную запись для доступа к активу.
20. Нажмите **Назначить роль**.
21. Выберите созданную ранее роль.
22. Нажмите **Далее**.
23. Выберите область действия роли.
24. Нажмите **Назначить роль**.
