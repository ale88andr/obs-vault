**Задача.** Чтобы выполнить проверку подключения:

1. Сравните время на сканируемом узле и на сканирующем узле. Оно не должно отличаться больше, чем на сутки.
2. Запустите утилиту wbemtest на сканирующем узле для взаимодействия со службой WMI сканируемого узла.
   > [!note] Примечание
   > Утилиту wbemtest необходимо запускать от имени учетной записи, с помощью которой выполнен вход в Positive Technologies MaxPatrol VM. По умолчанию это локальная системная учетная запись (SYSTEM).
3. Если Positive Technologies MaxPatrol VM запущен от имени доменной учетной записи:
   - Убедитесь, что wbemtest запускается от имени доменной записи, или что ваша учетная запись имеет такие же права на доступ по сети к сканируемому узлу.
   - В командной строке Windows выполните команду `wbemtest`.
   → Откроется окно **Тестер инструментария управления Windows**.
4. Если Positive Technologies MaxPatrol VM запущен от имени системной учетной записи:
   - Загрузите комплект программ PsTools, доступный на сайте [technet.microsoft.com](http://technet.microsoft.com/ru-ru/sysinternals/bb897553.aspx).
   - Распакуйте `PsTools.zip`, например в папку `C:\PsTools`.
   - Запустите интерпретатор командной строки `cmd.exe` от имени администратора.
   - Запустите wbemtest с помощью PsExec:
   ```
   C:\PsTools\PsExec.exe -i -s wbemtest
   ```
   → Откроется окно **Тестер инструментария управления Windows**.
5. Нажмите **Подключить** для проверки возможности соединения со службой WMI сканируемого узла.
   ![[760239115.png]]

   *Проверка подключения*
   → Откроется окно **Подключение**.
6. Укажите параметры подключения в соответствующих полях и нажмите **Подключить**.
   ![[759985035.png]]

   *Проверка возможности соединения*
7. В окне **Тестер инструментария управления Windows** нажмите **Запрос**.
   ![[760229515.png]]

   *Создание запроса*
8. Укажите контрольный запрос для WMI:
   ```
   select * from win32_operatingsystem
   ```
9. Нажмите **Применить**.

![[760231435.png]]

*Выполнение запроса*
