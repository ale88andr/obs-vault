# Выпуск токена доступа для учетной записи

> [!warning] Внимание
> На узле актива должна быть установлена программа cURL.

**Задача.** Чтобы выпустить токен доступа:

1. На узле, с которого производится настройка, запустите терминальный клиент, поддерживающий протокол SSH.
2. Пройдите аутентификацию на активе.
3. Выполните команду:
   ```bash
   curl -u <Логин учетной записи администратора>:<Пароль учетной записи администратора> -XPOST "http://localhost:8081/artifactory/api/security/token" -d "username=<Логин учетной записи для доступа к активу>" -d "expires_in=<Срок действия токена доступа>"
   ```
   → Например:
   ```bash
   curl -u admin_login:admin_password -XPOST "http://localhost:8081/artifactory/api/security/token" -d "username=user_login" -d "expires_in=0"
   ```
4. Скопируйте токен доступа и сохраните в текстовый файл.

Токен доступа понадобится при добавлении учетной записи в MaxPatrol VM.
