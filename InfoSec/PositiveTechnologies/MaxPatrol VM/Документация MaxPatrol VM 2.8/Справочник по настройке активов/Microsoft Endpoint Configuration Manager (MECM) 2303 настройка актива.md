# Microsoft Endpoint Configuration Manager (MECM) 2303: настройка актива

Настройку актива нужно выполнять от имени учетной записи, имеющей права локального администратора ОС и поддерживающей в настраиваемом экземпляре СУБД роль sysadmin.

> [!warning] Внимание
> При использовании в IT-инфраструктуре организации межсетевого экрана или других средств для контроля сетевого трафика требуется настроить в них правила, разрешающие трафик в обоих направлениях между узлом актива и узлом MP 10 Collector. Для проведения аудита используется порт 1433/TCP.

Данные об узлах, зарегистрированных в Microsoft Endpoint Configuration Manager, сохраняются в БД под управлением СУБД Microsoft SQL Server. При проведении аудита эти узлы добавляются в MaxPatrol VM в качестве активов. Для каждого актива указывается информация о версии ОС и установленном ПО.

Для проведения аудита на активе нужно:

1. Создать [локальную](https://help.ptsecurity.com/ru-RU/projects/vm/2.8/help/3552296459) или [[Создание доменной учетной записи [Настройка доступа в СУБД Microsoft SQL Server]|доменную]] учетную запись пользователя Windows.

   > [!note] Примечание
   > Данные этой учетной записи нужно указать при добавлении учетной записи в MaxPatrol VM.
2. Настроить [[Настройка локальной политики безопасности для удаленного доступа|локальную]] или [[Настройка групповой политики для удаленного доступа [Настройка доступа в СУБД Microsoft SQL Server]|групповую]] политику безопасности для удаленного доступа учетной записи.
3. Настроить локальную или [[Настройка групповой политики для раздела реестра|групповую]] политику безопасности для доступа учетной записи к разделам реестра.
4. Предоставить учетной записи полномочия роли db_datareader.
5. Настроить [[Настройка портов TCPIP|порты TCP/IP для подключения к СУБД]].
6. Включить [[Включение правила межсетевого экрана Windows|правило межсетевого экрана Windows]], разрешающее подключение к порту базы данных.
