# Добавление учетной записи для доступа по SSH

**Задача.** Чтобы добавить в MaxPatrol VM учетную запись для доступа к активу:

1. В главном меню выберите **Сбор данных** → **Учетные записи**.
2. Нажмите **Добавить учетную запись** → **Логин — пароль**.
3. Введите название учетной записи.
4. В раскрывающемся списке **Метки** установите флажок **Terminal**.
5. Введите логин учетной записи.
6. Введите пароль и подтвердите его.
7. Нажмите **Сохранить**.

Для аудита коммутаторов серии HPE 1900 необходимо добавить дополнительную учетную запись.

**Задача.** Чтобы добавить в MaxPatrol VM дополнительную учетную запись:

1. В главном меню выберите **Сбор данных** → **Учетные записи**.
2. Нажмите **Добавить учетную запись** → **Логин — пароль**.
3. Введите название учетной записи.
4. Введите логин учетной записи `y`.
5. Введите пароль и подтвердите его.
   > [!warning] Внимание
   > Пароль должен совпадать с паролем первой учетной записи.
   > [!note] Примечание
   > Примеры известных предустановленных паролей для привилегированного доступа: для серии HPE 1910 — `512900`, для серии HPE 1920 — `512900` и `Jinhua1920unauthorized`, для серии HPE 1950 — `foes-bent-pile-atom-ship` и `Agnipath1950unauthorized`.
6. Нажмите **Сохранить**.
