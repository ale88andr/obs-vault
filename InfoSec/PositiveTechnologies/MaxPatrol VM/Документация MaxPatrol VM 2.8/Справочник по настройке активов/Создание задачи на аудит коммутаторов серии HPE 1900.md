# Создание задачи на аудит коммутаторов серии HPE 1900

Чтобы создать задачу на аудит коммутаторов серии HPE 1900:

1. В главном меню выберите **Сбор данных** → **Задачи**.
2. Нажмите **Создать задачу** → **Сбор данных**.
3. Введите название задачи.
4. В раскрывающемся списке **Профиль** выберите **SSH Network Device Audit**.
5. Выберите учетную запись для доступа к активу.
6. Включите отображение дополнительных параметров.
7. Включите отображение способа повышения привилегий и выберите **Другой**.
8. Введите команду для повышения привилегий в зависимости от серии коммутатора.
   → Например, для серий HPE 1910,1920 используется команда `_cmdline-mode on`, для серии HPE 1950 — `xtd-cli-mode`.
9. Включите отображение учетной записи для повышения привилегий и выберите добавленную дополнительную учетную запись.
10. Укажите последовательность выполнения команд **Команда, логин, пароль**.
11. Включите ожидание приглашения на ввод логина.
12. Включите ожидание приглашения на ввод пароля.
13. Выберите **Сканирование систем** → **Через терминал: SSH** → **Параметры SSH** → **Ввод логинов** и добавьте новое приглашение типа **Регулярное выражение**, указав регулярное выражение `.*\[Y\/N\]:$`.
14. Если требуется, выберите коллекторы для сбора данных.
15. В панели **Цели сбора данных** на вкладке **Включить** выполните одно из следующих действий:
    - Если для сканируемой цели ранее был добавлен актив, в поле **Активы** введите IP-адрес или доменное имя (в формате FQDN) узла актива.
    - Если для сканируемой цели актив ранее не был добавлен, в поле **Сетевые адреса** введите ее IP-адрес или доменное имя (в формате FQDN).
    > [!note] Примечание
    > В панели **Расписание** вы можете включить и настроить автоматический запуск задачи.
16. Нажмите **Сохранить**.
