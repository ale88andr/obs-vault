**Задача.** Чтобы добавить в MaxPatrol VM учетную запись для доступа к активу:

1. В главном меню выберите **Сбор данных** → **Учетные записи**.
2. Нажмите **Добавить учетную запись** → **Пароль**.
3. Введите название учетной записи.
4. В раскрывающемся списке **Метки** выберите **Web_API**.
5. В поле **Пароль** введите [[Создание токена доступа|сгенерированный токен]] и повторите его в поле **Подтверждение пароля**.
6. Нажмите **Сохранить**.
