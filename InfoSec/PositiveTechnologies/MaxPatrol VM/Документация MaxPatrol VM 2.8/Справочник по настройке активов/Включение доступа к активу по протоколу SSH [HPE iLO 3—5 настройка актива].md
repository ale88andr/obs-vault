**Задача.** Чтобы включить доступ к активу по протоколу SSH:

1. Войдите в веб-интерфейс программы HPE iLO под учетной записью c правами Configure iLO Settings.
2. В левой части страницы выберите **Administration** → **Access Settings**.
   ![[3995037067.png]]

   *Включение доступа к активу по протоколу SSH*
3. В раскрывающемся списке **Secure Shell (SSH) Access** выберите значение **Enabled**.
4. Нажмите кнопку **Apply**.

> Доступ к активу по протоколу SSH включен.
