Если сканирование выполняется не от доменной учетной записи, включенной в группу локальных администраторов, необходимо отключить сетевые ограничения UAC.

**Задача.** Чтобы отключить сетевые ограничения UAC на сканируемом узле:

1. В командной строке Windows выполните команду `regedit`.
   → Откроется окно **Редактор реестра**.
   ![[760233355.png]]

   *Редактирование реестра*
2. В иерархическом списке выберите **Компьютер** → **HKEY_LOCAL_MACHINE** → **SOFTWARE** → **Microsoft** → **Windows** → **CurrentVersion** → **Policies** → **System**.
3. В списке параметров выберите **LocalAccountTokenFilterPolicy**.
   → Если параметр отсутствует, в контекстном меню каталога **System** выберите пункт **Создать** → **Параметр DWORD (32 бита)** и укажите название **LocalAccountTokenFilterPolicy**.
   ![[760235275.png]]

   *Редактирование реестра*
4. В контекстном меню параметра **LocalAccountTokenFilterPolicy** выберите пункт **Изменить**.
   → Откроется окно **Изменение параметра DWORD (32 бита)**.
5. В поле **Значение** укажите **1**.
   ![[760237195.png]]

   *Редактирование реестра*
6. Нажмите **ОК**.
7. Перезагрузите узел.

> UAC отключен для всех учетных записей сканируемого узла при удаленных подключениях.
