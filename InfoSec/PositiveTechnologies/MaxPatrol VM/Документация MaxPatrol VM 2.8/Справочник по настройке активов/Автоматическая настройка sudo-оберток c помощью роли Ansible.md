# Автоматическая настройка sudo-оберток c помощью роли Ansible

Для этого сценария настройки нужно использовать архив `sudo_wrappers_ansible_role.tar` из архива `audit-sudo-wrappers.zip`, входящего в комплект поставки MaxPatrol 10.

На узле, с которого будет выполняться централизованная настройка, должны быть выполнены следующие условия:

- установлена система управления конфигурациями Ansible версии 2.9 или выше;
- установлена Python-библиотека passlib;
- при настройке активов от имени учетной записи, использующей связку «логин — пароль», установлен пакет `sshpass`.

На активах, которые будут настраиваться, должны быть выполнены следующие условия:

- установлен Python 2 (версия 2.6 или выше) или Python 3 (версия 3.5 или выше);
- создана учетная запись с общими данными для всех настраиваемых активов (связка «логин — пароль» или SSH-ключ);
- для команды sudo в дистрибутивах операционной системы «Альт» политика control настроена в режиме public (см. раздел [[Настройка политики control для команд su и sudo в операционной системе «Альт»]]).

При применении роли к активу выполняются следующие действия:

- проверяется наличие необходимых утилит для сканирования;
- создается учетная запись для сканирования;
- в домашнем каталоге учетной записи создаются файлы-обертки для утилит с возможностью их запуска через программу sudo;
- изменяются правила в конфигурационном файле `/etc/sudoers.d/<Логин учетной записи>` для предоставления учетной записи прав на запуск утилит сканирования с повышенными привилегиями.

> [!note] Примечание
> В качестве учетных данных может использоваться как связка «логин — пароль», так и SSH-ключ.

**Задача.** Чтобы запустить роль Ansible:

1. Скопируйте архив `sudo_wrappers_ansible_role.tar` на узел, с которого будет производиться централизованная настройка.
2. Распакуйте архив:
   ```
   tar -xvf sudo_wrappers_ansible_role.tar
   ```
3. Перейдите в каталог с файлами роли:
   ```bash
   cd sudo_wrappers_ansible_role
   ```
4. Откройте на редактирование инвентарный файл `hosts`.
5. В параметре `ansible_user` укажите логин учетной записи для настройки актива.
   > [!note] Примечание
   > Если какой-то из активов использует нестандартный порт для SSH, необходимо указать этот порт в параметре `ansible_port`. Например, `ansible_port=2222`.
6. После блока параметров `targets` построчно перечислите адреса активов, на которых будет настраиваться команда sudo.
   > [!note] Примечание
   > Если какой-то из активов использует нестандартный порт для SSH, необходимо указать этот порт рядом с IP-адресом в параметре `ansible_port`. Например, `10.10.10.10 ansible_port=2222`.
7. Сохраните изменения и закройте файл.
8. Задайте необходимые значения переменных (см. таблицу ниже) в файле `sudo-wrappers-config/defaults/main.yml`.
9. Если планируется использовать вариант конфигурации с SSH-ключом, вставьте содержимое ключа создаваемой учетной записи в файл `sudo-wrappers-config/files/mp_ssh_key.pub`.
10. Выполните команду для запуска роли на всех активах, указанных в инвентарном файле:
    ```
    ansible-playbook -i hosts --ask-become-pass sudo-wrappers-config.yml
    ```
    > [!note] Примечание
    > При настройке активов от имени учетной записи, использующей связку «логин — пароль», необходимо добавить к команде запуска параметр `--ask-pass`. При использовании этого параметра в начале выполнения роли будет запрошен пароль, указанный в параметре `ansible_user`.
11. Введите пароль учетной записи, от имени которой производится настройка актива.
12. Введите логин учетной записи для доступа к активу (по умолчанию — `mpuser`).
13. Введите пароль учетной записи для доступа к активу и подтвердите его.

> [!note] Примечание
> Если доступ к активам осуществляется по логину и паролю, Ansible запросит пароль.

**Переменные в файле sudo-wrappers-config/defaults/main.yml**

| Переменная | Описание |
| --- | --- |
| `mp_user_name` | Логин учетной записи MaxPatrol 10 для аудита актива (по умолчанию — `mpuser`) |
| `mp_user_set_passwd` | Указывает, будет ли учетная запись MaxPatrol 10 использовать пароль для входа в систему. Принимает значения `true` или `false` (по умолчанию — `true`) |
| `mp_user_set_ssh_key` | Указывает, будет ли учетная запись MaxPatrol 10 использовать SSH-ключ для входа в систему. Принимает значения `true` или `false` (по умолчанию — `false`) |

Для удобства модификации и добавления пользовательских параметров переменные, отвечающие за обработку специфики каждого дистрибутива, вынесены в файл `sudo-wrappers-config/vars/main.yml`.

> [!note] Примечание
> При запуске роль Ansible осуществляет проверку переменных, которая останавливается, если в обеих переменных `mp_user_set_passwd` и`mp_user_set_ssh_key` указано значение `false`.
