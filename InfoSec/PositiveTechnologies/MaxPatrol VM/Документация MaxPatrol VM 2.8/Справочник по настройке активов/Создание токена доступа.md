**Задача.** Чтобы создать токен для учетной записи:

1. Войдите в веб-интерфейс JetBrains TeamCity [[Создание учетной записи [JetBrains TeamCity Server 2018—2023 настройка актива]|под созданной учетной записью]].
2. Нажмите **Profile** → **Access Tokens**.
3. Нажмите **Create access token**.
4. В поле **Token name** введите название токена.
5. Если требуется ограничить время действия токена, введите время в поле **Expire in**.
6. В раскрывающемся списке **Permissions scope** выберите **<Same as current user>**.
7. Нажмите **Create**.
   > [!warning] Внимание
   > Нужно скопировать и сохранить полученный токен доступа. После обновления страницы его просмотр и копирование будут недоступны.
