**Задача.** Чтобы включить и настроить службу DCOM:

1. С помощью командной строки Windows запустите утилиту dcomcnfg.
   → Откроется окно **Службы компонентов**.
2. В иерархическом списке выберите **Службы компонентов** → **Компьютеры** → **Мой компьютер** и с помощью контекстного меню откройте свойства.
   ![[760227595.png]]

   *Просмотр свойств узла*
   → Откроется окно **Свойства: Мой компьютер**.
3. Выберите вкладку **Свойства по умолчанию** и убедитесь, что установлен флажок **Разрешить использование DCOM на этом компьютере**.
   ![[759986955.png]]

   *Настройка свойств по умолчанию*
4. Выберите вкладку **Набор протоколов** и убедитесь, что в области **Протоколы DCOM** указан протокол **TCP/IP с ориентацией на подключения**.
   ![[760206475.png]]

   *Настройка протоколов*
5. Если протокол **TCP/IP с ориентацией на подключения** не добавлен, нажмите **Добавить**.
   → Откроется окно **Выбор протокола DCOM**.
   ![[760214155.png]]

   *Выбор протокола подключения*
6. Выберите протокол **TCP/IP с ориентацией на подключения**.
7. Нажмите **ОК**.
8. Перезагрузите узел.

> Служба DCOM настроена.
