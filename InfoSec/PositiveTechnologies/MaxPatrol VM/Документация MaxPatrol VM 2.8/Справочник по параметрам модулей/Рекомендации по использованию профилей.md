Перед проведением аудита IT-инфраструктуры организации необходимо найти активы модулем HostDiscovery.

Рекомендации, приведенные в разделе, позволяют увеличить скорость сканирования, сократить нагрузку на сетевую инфраструктуру и повысить эффективность аудита.

## Профили модуля HostDiscovery

Необходимо исключить блокировку ICMP при настройке профилей на основе модуля HostDiscovery. Для этого при создании нового профиля в блоке параметров **Параметры профиля** → **Способы проверки узлов** рекомендуется отключить проверку с помощью эхо-запроса. Рекомендуется проводить проверку с помощью SYN-пакетов, указав следующие порты TCP: 21, 22, 25, 53, 80, 110, 123, 139, 143, 443, 445, 465, 631, 993, 995, 3389.

В блоке параметров **Параметры профиля** → **Параметры проверки узлов** в дополнительных параметрах рекомендуется включить определение ОС и проверку с помощью ARP-запросов. Для безопасного сканирования рекомендуется ввести значение до 100 пак./с для параметров **Максимальная скорость отправки ARP-запросов** и **Максимальная скорость отправки пакетов**.

Для того чтобы подобрать оптимальную скорость отправки пакетов, рекомендуется несколько раз провести мониторинг сканирования с разными значениями параметров **Максимальная скорость отправки ARP-запросов** и **Максимальная скорость отправки пакетов**. По результатам мониторинга вы можете выбрать для них оптимальное значение.

## Профили модуля Audit

Активы, найденные модулем HostDiscovery, рекомендуется проверить с помощью модуля Audit.

Для быстрого аудита Windows рекомендуется использовать профиль Windows Updates Discovery.

Если в инфраструктуре один контроллер домена, рекомендуется использовать профиль Windows DC Audit.

Если в инфраструктуре несколько контроллеров домена, рекомендуется выбрать два контроллера домена и сканировать их профилем Microsoft Active Directory Audit. Остальные контроллеры домена рекомендуется сканировать профилем Windows Audit.

## Профили модуля MP8ScanImporter

При переносе данных из MaxPatrol 8 в MaxPatrol VM рекомендуется использовать профиль MP8ScanImporter.

## Профили модуля Pentest

Для эффективного и безопасного сканирования в режиме пентеста рекомендуется использовать профиль Safe PenTest.

Для проверки на наличие определенных уязвимостей рекомендуется создать задачу **Поиск уязвимостей в режиме пентеста** и указать в ней CVE-идентификаторы. Система автоматически создаст профиль с нужными параметрами.

## Профили модуля WebЕngine

При создании нового профиля на основе WebEngine в блоке параметров **Параметры профиля** → **Сбор данных** рекомендуется указывать стандартные порты TCP 80 и 443. В задачах на сбор данных с модулем WebEngine также рекомендуется использовать эти порты.

Для параметра **Полнота сбора данных** рекомендуется выбрать подходящий режим:

- **optimal** — для большинства сценариев;
- **fast** — для сокращения времени сканирования целей с большим количеством путей и параметров;
- **full** — для увеличения полноты покрытия целей с небольшим количеством путей и параметров, а также для ручных проверок и проверок с большим временным интервалом.

> [!warning] Внимание
> При сканировании в режиме **fast** некоторые уязвимости могут не обнаруживаться. При сканировании в режиме **full** могут появиться дубликаты уязвимостей, а также может увеличиться количество ложных срабатываний.
