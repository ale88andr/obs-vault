Запрос для создания задачи с помощью API версии 4.

Для выполнения запроса требуется аутентификация по протоколу OAuth с токеном доступа типа Bearer.

Метод и URL запроса:

```
POST <Корневой URL API>/api/scanning/v4/scanner_tasks/create
```

Тело запроса может содержать параметры, описанные в таблице ниже.

**Параметры в теле запроса /api/scanning/v4/scanner_tasks/create**

| Параметр | Обязательный | Тип данных | Описание |
| --- | --- | --- | --- |
| `task` | Нет | Object | Задача |
| Параметры задачи |   |   |   |
| `name` | Да | String | Название задачи |
| `description` | Нет | String | Описание задачи |
| `agents` | Нет | Array | Коллекторы и их компоненты, которые выбираются для выполнения задачи (расширенный вариант): - `agentIds` — идентификаторы коллекторов. Тип данных String; - `components` — принадлежность заданных для выполнения задачи коллекторов к конкретному конвейеру или ядру: - `siemIds` — конвейеры, коллекторы которых можно использовать для выполнения подзадачи. Тип данных String; - `useCoreAgents` — возможно ли использовать коллекторы ядра для выполнения подзадачи. Тип данных Bool |
| `scope` | Да | String | Задача по инфраструктуре |
| `profile` | Да | String | Основной профиль сканирования |
| `include` | Да | Array | Признак включения целей сбора данных: - `assets` — активы: - `id` — идентификатор актива Тип данных String; - `name` — имя актива. Тип данных String; - `id` — идентификатор группы активов. Тип данных String; - `name` — название группы активов. Тип данных String |
| `exclude` | Да | Array | Признак исключения целей сбора данных: - `assets` — активы: - `id` — идентификатор актива. Тип данных String; - `name` — имя актива. Тип данных String; - `id` — идентификатор группы активов. Тип данных String; - `name` — название группы активов. Тип данных String |
| `hostDiscovery` | Да | Array | Признак обнаружения узлов до начала сбора данных: - `enabled` — сканировать ли отвечающие узлы. Тип данных Bool; - `profile` — профиль: - `id` — идентификатор профиля. Тип данных String; - `name` — название профиля. Тип данных String |
| `triggerParameters` | Да | Array | Базовые параметры срабатывания по таймеру: - `type` — тип срабатывания. Тип данных String; - `fromDate` — дата начала срабатывания. Тип данных String; - `toDate` — дата окончания срабатывания. Тип данных String; - `isEnabled` — разрешено ли срабатывание по таймеру. Тип данных Bool |
| `isFqdnPriority` | Нет | Bool | Является ли сканирование активов по FQDN более приоритетным, чем сканирование по IP-адресу |
| `overrides` | Нет | Array | Переопределение параметров профиля. Каждая строка представлена массивом значений столбцов строки в порядке, объявленном в схеме: `additionalProp1`, `additionalProp2`, `additionalProp3` |
| `savepoints` | Нет | Array | Точки сохранения: - `target` — цель задачи сканирования. Тип данных String; - `savepoint` — точка сохранения. Тип данных String |

## Ответ на запрос

В ответ на успешный запрос сервис возвращает код 200 (OK). Ответ может содержать поля, описанные в таблице ниже.

**Поля ответа на запрос /api/scanning/v4/scanner_tasks/create**

| Поле | Тип данных | Описание |
| --- | --- | --- |
| `id` | String | Идентификатор задачи |

Возможные коды ошибок и их значения:

- 400 (Bad request) — синтаксическая ошибка в запросе. Ответ может содержать поля, описанные в таблице ниже.

**Поля ответа на запрос /api/scanning/v4/scanner_tasks/create**

| Поле | Тип данных | Описание |
| --- | --- | --- |
| `errors` | Array | Ошибки: - `error` — ошибка: - `type` — тип ошибки; - `category` — категория ошибки; - `displayName` — отображаемое имя; - `hostName` — имя узла; - `ipAddresses` — IP-адрес; |
| `message` | String | Сообщение |
| `code` | Integer | Код ошибки |
