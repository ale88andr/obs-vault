# Получение ошибок, произошедших при выполнении подзадачи

Запрос для получения ошибок, произошедших при выполнении подзадачи.

Для выполнения запроса требуется аутентификация по протоколу OAuth с токеном доступа типа Bearer.

Параметры строки запроса описаны в таблице ниже.

```
GET <Корневой URL API>/api/scanning/v2/jobs/{jobId}/job_errors
```

URL запроса содержит path-параметр `jobId` — идентификатор подзадачи.

Параметры строки запроса описаны в таблице ниже.

**Параметры строки запроса /api/scanning/v2/jobs/{jobId}/job_errors**

| Параметр | Обязательный | Тип данных | Описание |
| --- | --- | --- | --- |
| `offset` | Нет | Integer | Смещение от начала результатов выборки |
| `limit` | Нет | Integer | Количество запрашиваемых в выборке элементов |
| `orderby` | Нет | String | Сортировка по колонке `occurredAt` в направлении `asc` или `desc`. Пример значения: `orderby="startedAt desc"` |

В ответ на успешный запрос сервис возвращает код 200 (OK). Ответ может содержать поля, описанные в таблице ниже.

**Поля ответа на запрос /api/scanning/v2/jobs/{jobId}/job_errors**

| Поле | Тип данных | Описание |
| --- | --- | --- |
| Поля списка ошибок подзадач |   |   |
| `items` | String | Список ошибок |
| `totalItems` | Integer | Общее количество ошибок, попадающих в выборку |
| `logsDownloadUnavailable` | Bool | Возможно ли скачать журнал подзадачи с помощью коллектора |
| Параметры списка ошибок подзадач |   |   |
| `occurredAt` | String | Время ошибки в формате ISO 8601 |
| `sourceName` | String | Псевдоним источника ошибки |
| `type` | String | Тип ошибки, идентификатор шаблона для вывода |
| `parameters` | Array | Параметры для подстановки в шаблон |
| `status` | String | Статус ошибки |

Возможные коды ошибок и их значения:

- 400 (Bad request) — синтаксическая ошибка в запросе.
