Запрос для получения информации об используемых в задаче коллекторах.

Для выполнения запроса требуется аутентификация по протоколу OAuth с токеном доступа типа Bearer.

Параметры строки запроса описаны в таблице ниже.

```
GET <Корневой URL API>/api/scanning/v2/runs/{runId}/agents
```

URL запроса содержит path-параметр `runId` — идентификатор запуска задачи.

В ответ на успешный запрос сервис возвращает код 200 (OK). Ответ может содержать поля, описанные в таблице ниже.

**Поля ответа на запрос /api/scanning/v2/runs/{runId}/agents**

| Поле | Тип данных | Описание |
| --- | --- | --- |
| `id` | String | Идентификатор коллектора |
| `name` | String | Наименование коллектора |
| `status` | String | Статус коллектора |

Возможные коды ошибок и их значения:

- 400 (Bad request) — синтаксическая ошибка в запросе.
