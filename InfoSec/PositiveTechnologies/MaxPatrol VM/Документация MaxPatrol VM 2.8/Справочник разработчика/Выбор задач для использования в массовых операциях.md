Запрос для выбора задач для использования в массовых операциях.

Для выполнения запроса требуется аутентификация по протоколу OAuth с токеном доступа типа Bearer.

Метод и URL запроса:

```
POST <Корневой URL API>/api/scanning/v3/task_selections
```

Параметры строки запроса описаны в таблице ниже.

**Параметры строки запроса /api/scanning/v3/task_selections**

| Параметр | Обязательный | Тип данных | Описание |
| --- | --- | --- | --- |
| `mainFilter` | Нет | String | Основной фильтр |
| `additionalFilter` | Нет | String | Дополнительный фильтр. Значение по умолчанию: `all` |
| `token` | Нет | String | Токен выборки. Возвращает задачи из кэша. Если параметр не задан, задачи возвращаются из базы данных |

Тело запроса может содержать параметры, описанные в таблице ниже.

**Параметры в теле запроса /api/scanning/v3/task_selections**

| Параметр | Обязательный | Тип данных | Описание |
| --- | --- | --- | --- |
| `filter` | Нет | Object | Параметры фильтра |
| `tasksIds` | Да | Array | Список идентификаторов выбранных и невыбранных задач: - `allSelected` — выбраны ли все задачи; - `unselected` — список идентификаторов невыбранных задач. Если параметр задан, параметр `selected` не задается; - `selected` — список идентификаторов выбранных задач. Если параметр задан, параметр `unselected` не задается |
| Параметры фильтра |   |   |   |
| `text` | Нет | String | Текст |
| `agents` | Нет | Array | Коллектор: - `agentIds` — идентификаторы коллекторов; - `autoSelect` — включен ли автовыбор |
| `modules` | Нет | String | Модули |
| `profiles` | Нет | String | Профили |
| `statuses` | Нет | String (Enum) | Статус задачи сканирования |
| `credentials` | Нет | String | Учетные записи |
| `target` → `target` | Да | Array | Атакованные активы: - `assets` — активы: - `id` — идентификаторы активов; - `name` — названия активов - `id` — идентификаторы групп активов; - `name` — названия групп активов |
| `target` → `type` | Да | String | Тип атакованного актива |
| `scopes` | Нет | String | Задача по инфраструктуре |

## Ответ на запрос

В ответ на успешный запрос сервис возвращает код 200 (OK). Ответ может содержать поля, описанные в таблице ниже.

**Поля ответа на запрос /api/scanning/v3/task_selections**

| Поле | Тип данных | Описание |
| --- | --- | --- |
| `selectionId` | String | Идентификатор выборки |
| `selectedTasksCount` | Integer | Количество выбранных задач |
| `availableOperations` | Array | Список доступных операций над задачей: - `Operation` — операция над задачей |
| `token` | String | Токен |

Возможные коды ошибок и их значения:

- 400 (Bad Request) — синтаксическая ошибка в запросе.
