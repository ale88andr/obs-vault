# Создание шаблона для экспорта записей

Для генерации отчетов из шаблонов в формате XLSX MaxPatrol VM использует инструмент ClosedXML.Report. В файлах шаблонов, помимо неизменяемого содержимого, вы можете указывать переменные и выражения в двойных фигурных скобках.

Переменные обозначают параметры PDQL-запроса, соответствующего шаблону, и имеют вид `{{item.<Параметр из PDQL-запроса>}}`, например `{{item.Host.OsName`}}. Если переменная передана без имени, ее поля и свойства доступны в шаблоне как самостоятельные переменные под своими именами. При генерации отчета переменные заменяются на значения, получаемые с помощью соответствующих им параметров PDQL-запроса.

Выражения позволяют выполнять вычисления и фильтрацию данных на основе переменных. В выражениях поддерживаются лямбда-выражения.

Формулы, содержащие переменные, необходимо экранировать: заменить символ `=` в начале формулы на `&`. Например: `&=CONCATENATE({{Addr1}}," ",{{Addr2}})`. Экранированные формулы необходимо записывать в международном синтаксисе: названия функций указывать латиницей и использовать в качестве разделителя значений запятую.

Подробная информация о возможностях инструмента ClosedXML.Report доступна на его [официальном сайте](https://closedxml.io/ClosedXML.Report/).

> [!note] Примечание
> Если для обозначения параметра в PDQL-запросе используется алиас, необходимо его использовать при указании переменной. Например, `Host.IpAddress as IpAddress` соответствует переменной `{{item.IpAddress}}`.

Переменные в шаблоне необходимо размещать внутри именованной области. Для корректного формирования отчета область должна:

- быть непрерывной и иметь прямоугольную форму;
- иметь имя вида `DataArea_<Номер области в шаблоне>`, например `DataArea_1`;
- включать не менее двух столбцов и двух строк, так как крайний левый столбец и крайняя нижняя строка всегда являются служебными и предназначены для специальных тегов, например для сортировки данных в ячейках.

> [!warning] Внимание
> Microsoft Excel может автоматически преобразовывать поля шаблона в формулы. Например, в поле `{{item.Host@Ip.Adressess}}` может добавиться функция `HYPERLINK`, что приведет к ошибке при загрузке шаблона. Рекомендуется проверять шаблон до и после его сохранения.

**Задача.** Чтобы создать шаблон для экспорта записей:

1. Создайте файл формата XLSX с помощью Microsoft Excel или любого другого редактора, который поддерживает изменение файлов формата XLSX.
   > [!warning] Внимание
   > Пользовательский шаблон необходимо создать в новом файле. Не следует копировать файл системного шаблона, так как это может привести к возникновению ошибок.
   → В созданном файле отступите от верха листа не менее двух строк и выделите область высотой две строки и длиной N+1 ячеек, где N — количество параметров в PDQL-запросе, по которому в шаблон будут выгружаться данные. Например, для запроса `select(@Host, Host.OsName, Host.OsVersion, Host.@UpdateTime)` необходимо выделить область размером две на четыре ячейки.
   ![[6168151819.png]]

   *Выделение области в шаблоне*
2. В контекстном меню выделенной области выберите **Присвоить имя**.
3. В открывшемся окне в поле **Имя** введите `DataArea_<Номер области>` и нажмите кнопку **OK**.
4. В созданной области оставьте свободной первую ячейку первой строки, а в остальные последовательно добавьте переменные вида `{{item.<Параметр из PDQL-запроса>}}`, соответствующие параметрам PDQL-запроса. Например, для запроса `select(@Host, Host.OsName, Host.OsVersion, Host.@UpdateTime)` необходимо добавить переменные `{{item.Host.OsName}}`, `{{item.Host.OsVersion}}` и `{{item.Host.UpdateTime}}`.
   ![[6168152331.png]]

   *Добавление переменных в шаблон*
5. В ячейки над переменными добавьте названия соответствующих столбцов.
   ![[6168152843.png]]

   *Добавление названий столбцов*
6. Если требуется сортировать экспортируемые данные, добавьте тег `<<Sort>>` в служебную ячейку под соответствующей переменной.
   > [!note] Примечание
   > Тег `<<Sort>>` применяет к переменной сортировку по возрастанию значений. Для сортировки по убыванию значений вы можете использовать тег `<<Sort Desc>>`.
   > [!warning] Внимание
   > Не рекомендуется использовать теги сортировки в шаблоне, так как это значительно замедлит генерацию отчета. Сортировку следует выполнять в PDQL-запросе с помощью функции `sort`.
   ![[6168153355.png]]

   *Добавление тега сортировки данных*
7. Если ячейки содержат ссылки и при экспорте записей их требуется сохранить активными, [[Экспорт записей с активными ссылками|настройте экспорт ссылок с помощью тегов]].
8. Сохраните изменения в файле.

> Шаблон создан. Вы можете [[Загрузка шаблона для экспорта записей|загрузить]] его в MaxPatrol VM.

Вы также можете добавлять в шаблоны дополнительные области для экспорта записей из PDQL-запросов — как на том же листе справа или ниже от добавленной ранее области (с учетом служебных строк и столбцов), так и на другие листы шаблона.

После создания шаблона рекомендуется проверить корректность его работы. Для этого необходимо выполнить экспорт записей с использованием шаблона и открыть полученный файл. Шаблон сформирован верно, если:

- столбцы заполнены данными;
- данные соответствуют названиям столбцов;
- в ячейках отсутствуют сообщения об ошибках.

Если в файле есть пустые столбцы или сообщения об ошибках, необходимо проверить соответствие переменных в шаблоне параметрам PDQL-запроса.
