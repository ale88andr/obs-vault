# Создание задачи на экспорт записей об активах с применением шаблона в формате XLSX

**Задача.** Чтобы создать задачу на экспорт записей об активах с применением шаблона:

1. В главном меню выберите **Система** → **Отчеты**.
2. В панели инструментов нажмите **Создать**.
3. Выберите **Экспорт записей** и нажмите **Далее**.
   → Откроется окно **Новая задача на выпуск отчета**.
4. В поле **Название** введите название задачи.
5. Выберите **XLSX** в качестве формата файла для экспорта записей.
   > [!note] Примечание
   > Вы можете изменить количество экспортируемых записей по ссылке **Изменить**. В файл любого из поддерживаемых форматов можно экспортировать не более одного миллиона записей.
6. В раскрывающемся списке **Источник** выберите **Активы**.
7. В раскрывающемся списке **Группы** установите флажки напротив групп активов, для которых необходимо экспортировать записи.
8. В раскрывающемся списке **Запросы** выберите PDQL-запрос, в соответствии с которым необходимо экспортировать записи.
   > [!note] Примечание
   > Вы можете выбрать несколько PDQL-запросов. Для экспорта записей по нескольким запросам необходимо [[Создание шаблона для экспорта записей|создать]] и [[Загрузка шаблона для экспорта записей|загрузить]] в систему соответствующий шаблон, в котором должны быть размечены области для выгрузки записей по каждому из выбранных запросов. Например, для выгрузки записей по трем PDQL-запросам в шаблоне должны быть размечены три области.
9. Включите использование шаблона для экспорта данных.
10. В раскрывающемся списке **Шаблон** выберите шаблон, соответствующий выбранным PDQL-запросам.
11. Если для экспорта записей выбраны несколько PDQL-запросов, в блоке параметров **Схема выгрузки данных** сопоставьте области шаблона выбранным PDQL-запросам.
12. Если требуется, настройте расписание, в соответствии с которым записи будут автоматически экспортироваться в указанное время с заданной периодичностью.
13. Нажмите **Сохранить**.
