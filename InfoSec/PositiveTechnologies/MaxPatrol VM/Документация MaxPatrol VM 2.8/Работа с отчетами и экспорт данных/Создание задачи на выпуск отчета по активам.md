# Создание задачи на выпуск отчета по активам

**Задача.** Чтобы создать задачу на выпуск отчета по активам:

1. В главном меню выберите **Система** → **Отчеты**.
2. В панели инструментов нажмите **Создать**.
   → Откроется окно **Создание задачи**.
3. В списке шаблонов выберите **Отчеты по активам и инцидентам**.
4. Нажмите кнопку **Далее**.
   → Откроется окно **Создание задачи**.
5. В поле **Название** введите название отчета.
6. В раскрывающемся списке **Источник** выберите **Активы**.
7. В раскрывающемся списке **Отчет** выберите шаблон отчета.
8. В раскрывающемся списке **В группе** выберите группу активов, данные о которых должны войти в отчет.
9. Если вы хотите, чтобы в отчет попадали также данные об активах из вложенных групп, установите флажок **Включая вложенные**.
10. Если требуется, настройте расписание, в соответствии с которым отчет будет автоматически выпускаться в указанное время с заданной периодичностью.
11. Нажмите **Сохранить** → **Сохранить задачу**.
    > [!note] Примечание
    > Вы можете сохранить созданную задачу в качестве шаблона. Для этого необходимо выбрать пункт **Сохранить в шаблон**. Созданный шаблон появится в библиотеке шаблонов и будет доступен всем пользователям. Для удаления шаблонов, созданных другими пользователями, необходимо обладать привилегией «Расширенные полномочия».
12. Нажмите **Обновить**.
13. Нажмите **Закрыть**.
