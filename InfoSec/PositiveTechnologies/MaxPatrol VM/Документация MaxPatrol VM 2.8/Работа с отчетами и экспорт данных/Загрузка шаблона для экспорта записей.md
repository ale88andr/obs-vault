**Задача.** Чтобы загрузить шаблон:

1. В главном меню выберите **Система** → **Шаблоны для экспорта записей (XLSX)**.
2. В панели инструментов нажмите **Загрузить**.
   → Откроется окно **Загрузка шаблона**.
3. Перетащите файл в область загрузки или загрузите файл по ссылке **выберите**.
4. Введите название шаблона.
5. Нажмите **Загрузить**.
