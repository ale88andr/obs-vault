# Создание задачи на экспорт записей об активах

**Задача.** Чтобы создать задачу на экспорт записей об активах:

1. В главном меню выберите **Система** → **Отчеты**.
2. В панели инструментов нажмите **Создать**.
   → Откроется окно **Создание задачи**.
3. Выберите **Экспорт записей** и нажмите **Далее**.
   → Откроется окно **Новая задача на выпуск отчета**.
4. В поле **Название** введите название задачи.
5. Выберите формат файла для экспорта записей.
   > [!note] Примечание
   > Вы можете изменить количество экспортируемых записей по ссылке **Изменить**. В файл любого из поддерживаемых форматов можно экспортировать не более одного миллиона записей.
6. В раскрывающемся списке **Источник** выберите **Активы**.
7. В раскрывающемся списке **Группы** установите флажки напротив групп активов, для которых необходимо экспортировать записи.
8. В раскрывающемся списке **Запросы** выберите PDQL-запрос, в соответствии с которым необходимо экспортировать записи.
9. Если требуется, настройте расписание, в соответствии с которым записи будут автоматически экспортироваться в указанное время с заданной периодичностью.
10. Нажмите **Сохранить**.
