После обнаружения активов и сканирования их модулем Pentest рекомендуется распределить активы по группам. Группы понадобятся в дальнейшем при планировании задач и политик. Группировка активов также используется при фильтрации данных для отчетов.

В MaxPatrol VM есть два вида групп для объединения активов:

- В статические группы активы необходимо добавлять вручную, а также они служат для объединения динамических групп.
- Динамические группы автоматически наполняются активами, которые соответствуют фильтру группы.

Ниже приведены общие рекомендации по планированию групп активов для инфраструктур разных размеров. В своей инфраструктуре вы можете применить комбинацию этих подходов.

После добавления групп активов рекомендуется настроить отправку уведомлений об изменениях в ключевых группах.

## До 1000 активов

Для инфраструктур, содержащих до 1000 активов, рекомендуется следующая структура групп.

**Группы для инфраструктур до 1000 активов**

| Верхний уровень | Статические группы | Динамические группы | Фильтры |
| --- | --- | --- | --- |
| Организация | Инфраструктурная роль | Active Directory | `Host.HostRoles.Role in ['Domain Controller', 'Directory Service']` |
| Организация | Инфраструктурная роль | Почтовые серверы | `Host.HostRoles.Role = 'Mail Server'` |
| Организация | — | Сетевое оборудование | `NetworkDeviceHost.Vendor` |
| Организация | Операционные системы | Linux и Unix | `LinuxHost or UnixHost` |
| Организация | Операционные системы/Windows | Рабочие станции | `WindowsHost.HostType = 'Desktop'` |
| Организация | Операционные системы/Windows | Серверы | `WindowsHost.HostType = 'Server'` |
| Организация | Сетевые сегменты | Демилитаризованная зона | `Host.IpAddress in 192.168.2.0/24` |
| Организация | Сетевые сегменты | IT test lab | `Host.IpAddress in 192.168.1.0/24` |
| Организация | Уязвимости | Уязвимости в Microsoft Exchange | `(Host.@Vulners.CVEs.Item = 'CVE-2021-26855') OR (Host.@Vulners.CVEs.Item = 'CVE-2021-26857') OR (Host.@Vulners.CVEs.Item ='CVE-2021-26858') OR (Host.@Vulners.CVEs.Item = 'CVE-2021-27065')` |
| Организация | Уязвимости | Уязвимости в Microsoft Office | `Host.Softs[@Vulners and (Name = "Microsoft Office" or Name = "Microsoft Word" or Name = "Microsoft Excel" or Name = "Microsoft PowerPoint")]` |

## До 10 000 активов

Для инфраструктур, содержащих от 1000 до 10 000 активов, рекомендуется создать три статических группы верхнего уровня:

- группа задач сканирования;
- группа контроля устаревания активов;
- группа для генерации отчетов.

**Задача.** Чтобы организовать активы для задач сканирования:

1. В группе задач сканирования создайте статические группы для серверного и сетевого оборудования и рабочих станций.
2. Внутри этих статических групп создайте динамические группы, которые будут использоваться как цели сканирования.

В серверной и сетевой инфраструктуре рекомендуется выделить следующие группы:

- Active Directory — статическая группа, содержащая один или два контроллера домена для сканирования с профилем Microsoft Active Directory Audit;
- контроллеры домена — динамическая группа для сканирования профилем Windows Audit;
- сетевые устройства;
- подсети в демилитаризованной зоне;
- Windows-серверы в домене;
- Windows-серверы не в домене — для их сканирования нужны отдельные учетные записи;
- Linux-серверы;
- рабочие станции — например, можно сгруппировать их по офисам.

> [!warning] Внимание
> Группы задач сканирования рекомендуется использовать только как цели сбора данных, причем каждой группе должна соответствовать только одна задача. Таким образом вы минимизируете вероятность ошибок при изменении параметров групп и задач.

Группы контроля предназначены для получения общей картины устаревания активов. Рекомендуется настроить их аналогично группам сканирования, но с меньшей детализацией. Например, можно объединить активы с Linux и Windows в одну группу.

С помощью групп контроля можно решать такие задачи, как контроль статуса ключевых активов, взлома которых нельзя допустить, инвентаризация активов и ежедневные проверки на уязвимости.

## Больше 10 000 активов

Для инфраструктур более чем с 10 000 активов вы можете добавить функциональные группы верхнего уровня:

- Информационная система;
- Службы каталогов;
- Управление доступом;
- Почта;
- Виртуализация;
- ИТ-инфраструктура:

- Управление;
- Мониторинг;

- VPN;
- Web;
- NAT;
- Публичные IP-адреса.

## Уведомления об изменениях в группах

По умолчанию уведомления отображаются на странице **Система** → **Уведомления**. Вы можете также [[Настройка SMTP-сервера для отправки уведомлений по электронной почте|получать уведомления по электронной почте]] или [настроить передачу уведомлений через POST-запросы](https://help.ptsecurity.com/ru-RU/projects/vm/2.8/help/1179033611).

**Задача.** Чтобы настроить уведомления об изменениях в группах активов:

1. В главном меню выберите **Система** → **Уведомления**.
2. Нажмите **Создать**.
3. Введите название уведомления.
4. В раскрывающемся списке **Сообщать** выберите **Об изменениях в группах активов**.
5. Выберите ключевые группы активов.
6. Нажмите **Сохранить**.
