# Создание задач на аудит

Модуль Audit предназначен для аудита активов методом белого ящика. В параметрах профиля нужно указать учетную запись, которой предоставлены права на выполнение команд для сбора данных об активе.

**Задача.** Чтобы создать задачи на аудит активов:

1. Добавьте в MaxPatrol VM учетные записи, согласованные с ИТ-департаментом.
   → Учетная запись для аудита актива должна иметь права на выполнение [[Команды, выполняемые при аудите активов|команд, необходимых для сбора данных об этом активе]]. Для аудита активов с Windows необходима учетная запись с правами администратора.
2. Определите профили, которыми будут сканироваться активы.
   → Выбор профиля зависит от значимости и доступности актива. Следует учитывать, что при выполнении аудита используются ресурсы актива и сети.
3. Создайте задачи на аудит активов с выбранными профилями.
   → При создании задач вы можете также указать периодичность и запрещенные интервалы их выполнения.
4. Проанализируйте результаты аудита и исправьте типичные ошибки.

В результате аудита в MaxPatrol VM могут быть добавлены новые активы. Рекомендуется выполнить на этих активах определение ОС модулем Pentest, чтобы распределить их по группам и назначить задачи аудита.

## Добавление учетных записей для задач сбора данных

Учетные записи используются для авторизации на активе для проведения аудита.

**Задача.** Чтобы добавить учетную запись в MaxPatrol VM:

1. В главном меню выберите **Сбор данных** → **Учетные записи**.
2. Нажмите **Добавить учетную запись** и выберите тип.
3. Заполните обязательные поля.

> [!note] Примечание
> В дополнение к названиям вы можете использовать метки, чтобы быстрее находить учетные записи.

## Профили для аудита активов

Учитывайте следующие сведения при планировании задач на аудит.

**Советы по выбору профилей для аудита**

| Профиль | Описание | Цели сбора данных |
| --- | --- | --- |
| Unix SSH Audit | Для аудита ОС семейства Unix и ПО, установленного на активах с такими ОС | Активы под управлением Linux и Unix |
| Windows DC Audit | Для сбора данных о ресурсах службы каталогов Microsoft Active Directory и аудита Windows по протоколам LDAP и RPC | Следует использовать на контроллере домена, если он один в сети |
| Microsoft Active Directory Audit | Для аудита ресурсов службы каталогов Microsoft Active Directory по протоколу LDAP | Следует использовать на одном из контроллеров домена, если в сети их несколько |
| Windows Audit | Для аудита Windows и ПО, установленного на активах под управлением Windows | Можно использовать на ключевых активах с Windows, например, контроллерах домена, которые не сканируются профилем Microsoft Active Directory Audit |
| Windows Updates Discovery | Профиль для быстрого аудита Windows и проверки установки обновлений. Задачи с этим профилем собирают ограниченный объем информации | Некритичные активы под управлением Windows |

> [!warning] Внимание
> Вы можете оптимизировать выполнение аудита с профилями Microsoft Active Directory Audit или Windows DC Audit, следуя инструкциям в разделе «[Microsoft Active Directory в Windows Server 2003—2022: настройка MaxPatrol VM](https://help.ptsecurity.com/ru-RU/projects/vm/2.8/help/3518836875)» Справочника по настройке источников.
