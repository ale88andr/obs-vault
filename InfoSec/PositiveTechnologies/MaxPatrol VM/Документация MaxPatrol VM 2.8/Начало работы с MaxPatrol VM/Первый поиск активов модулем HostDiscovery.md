Чтобы собрать базовую информацию об активах, рекомендуется просканировать инфраструктуру модулями HostDiscovery и Pentest.

## Сканирование инфраструктуры модулем HostDiscovery

Модуль предназначен для поиска активов в IT-инфраструктуре организации, не предназначен для поиска уязвимостей. Для проверки доступности активов используется ICMP ping, TCP ping или оба метода одновременно.

При сканировании модулем HostDiscovery скорость поступления SYN-пакетов на сетевые устройства может резко возрасти. Кроме того, быстро растут списки подключений на устройствах. Это может нарушить работоспособность сетевых устройств. Чтобы этого не произошло, важно определить оптимальные значения параметров HostDiscovery для вашей инфраструктуры.

**Задача.** Чтобы настроить HostDiscovery на оптимальную производительность:

1. Укажите в параметрах HostDiscovery скорость отправки 100 пакетов в секунду. Это безопасное значение для любых инфраструктур.
2. Согласуйте с ИТ-департаментом время начала сканирования и процедуру оперативной связи. ИТ-специалисты будут проводить мониторинг сетевой инфраструктуры в ходе сканирования.
3. Сообщите в ИТ-департамент о завершении сканирования.
4. В случае одобрения ИТ-специалистов увеличьте скорость отправки пакетов.

Повторите эту процедуру несколько раз, чтобы определить значения параметров модуля HostDiscovery, оптимальные с точки зрения скорости сканирования и нагрузки на сеть.

Ниже подробно описан процесс настройки модуля HostDiscovery.

## Поиск активов

Сканирование одного актива профилем HostDiscovery занимает до пяти минут. Для крупных инфраструктур рекомендуется сегментировать процесс поиска. Например, вы можете сегментировать поиск по подсетям, данные о которых предоставил ИТ-департамент.

**Задача.** Чтобы найти активы в инфраструктуре:

1. В главном меню выберите **Сбор данных** → **Задачи**.
2. Нажмите **Создать задачу** → **Сбор данных**.
3. Введите название задачи.
4. Выберите профиль **HostDiscovery**.
5. Отключите проверку с помощью эхо-запроса ICMP.
6. В поле **Порты TCP для проверки с помощью SYN-пакетов** укажите список часто используемых портов.
   → Пример:
   ```
   21, 22, 25, 53, 80, 110, 123, 139, 143, 443, 445, 465, 631, 993, 995, 3389
   ```
   > [!note] Примечание
   > Рекомендуется согласовать список портов с ИТ-департаментом.
7. Включите отображение дополнительных параметров сбора данных.
8. Выберите **Параметры проверки узлов**.
9. Включите определение операционной системы.
   > [!note] Примечание
   > Модуль HostDiscovery может определить семейство ОС. Более точно определить ОС можно с помощью модуля Pentest.
10. Для параметров **Максимальная скорость отправки ARP-запросов** и **Максимальная скорость отправки пакетов** укажите значения `100`.
    > [!note] Примечание
    > Эти значения в дальнейшем необходимо будет скорректировать на основе обратной связи от ИТ-департамента.
    ![[8553107083.png]]

    *Параметры первого поиска активов модулем HostDiscovery*
11. В поле **Сетевые адреса** укажите одну или несколько подсетей, предоставленных ИТ-департаментом.
    > [!warning] Внимание
    > Не рекомендуется указывать в качестве цели сбора данных подсети `/8` и меньше. Для первого поиска активов рекомендуется указывать подсети не меньше `/16`.
12. Нажмите **Сохранить и запустить** → **Запустить сбор данных**.

Указывая ограниченный список сканируемых портов TCP и только существующие подсети, вы можете максимально сократить время на первый поиск активов.
