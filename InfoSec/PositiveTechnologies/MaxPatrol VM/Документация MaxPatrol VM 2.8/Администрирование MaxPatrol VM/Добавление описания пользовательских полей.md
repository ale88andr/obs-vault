> [!warning] Внимание
> Имена элементов и атрибутов регистрозависимы, то есть при обработке файла `UserModel.xml` не игнорируется регистр символов.

**Задача.** Чтобы добавить описание пользовательских полей:

1. В файле `UserModel.xml` для элемента `layer id="UserDescriptions"` → `Entities` добавьте дочерний элемент `Entity` с атрибутом `Name`.
2. В качестве значения атрибута `Name` укажите алиас типа актива.
   → Например, для активов на Windows необходимо указать:
   ```xml
   <Entity Name="OperatingSystem.Windows.WindowsHost">
   </Entity>
   ```
   > [!note] Примечание
   > Названия алиасов по типу актива содержатся в Docker-контейнере службы Core Assets Processing в файле `/usr/local/share/microservice/layers/AssetAliases.xml`. Для входа в Docker-контейнер вы можете использовать команду `docker exec -t -i $(docker ps | awk '/assets-processing/ {print $NF}') /bin/bash`.
   > [!note] Примечание
   > При добавлении описания пользовательских полей значение атрибута `version` элемента `layer id="UserDescriptions"` несущественно. Вы можете оставить текущее значение или изменить его на любое другое.
3. Для элемента `Entity` добавьте дочерний элемент `Properties`:
   ```xml
   <Properties>
   </Properties>
   ```
4. Для элемента `Properties` добавьте дочерние элементы `Property` (по числу пользовательских полей с описанием) с атрибутом `Name`. В качестве значения атрибута `Name` укажите имя поля, например:
   ```xml
   <Property Name="UF_AssetNumber">
   </Property>
   ```
5. Для каждого элемента `Property` добавьте дочерний элемент `Title`. В качестве значения элемента `Title` укажите описание пользовательского поля.
   → Например:
   ```xml
   <Entity Name="OperatingSystem.Windows.WindowsHost">
   <Properties>
   <Property Name="UF_AssetNumber">
   <Title>Инвентарный номер актива в реестре</Title>
   </Property>
   <Property Name="UF_AssetOwner">
   <Title>Ответственный за актив:</Title>
   </Property>
   <Property Name="UF_DeploymentEnviroment">
   <Title>Среда dev, test, stage, prod</Title>
   </Property>
   <Property Name="UF_NetworkSegment">
   <Title>Сегмент сети LAN, DMZ</Title>
   </Property>
   <Property Name="UF_Countour">
   <Title>Контур</Title>
   </Property>
   <Property Name="UF_AssetRevisionDate">
   <Title>Дата последней ревизии актива</Title>
   </Property>
   </Properties>
   </Entity>
   ```

> Описание пользовательских полей добавлено.

Вы можете изменять значения элементов `Title` без изменения значения атрибута `version` для элемента `layer id="UserDescriptions"`.
