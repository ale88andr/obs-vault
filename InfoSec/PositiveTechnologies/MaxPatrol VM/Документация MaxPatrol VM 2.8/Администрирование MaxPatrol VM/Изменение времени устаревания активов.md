# Изменение времени устаревания активов

Параметр `DefaultAssetTtl` определяет срок, по истечении которого актив будет автоматически скрыт из интерфейса системы, если о нем не поступает новая информация (например, результаты сканирования).

Значение по умолчанию — 90 дней.

**Задача.** Чтобы изменить время устаревания активов,

1. измените конфигурацию роли Core, указав для параметра `DefaultAssetTtl` новое значение в формате `<Дни>.<Часы>:<Минуты>:<Секунды>`, например `30.00:00:00`.
