# Расположение пользовательских сертификатов

При резервном копировании и восстановлении данных вам могут потребоваться файлы пользовательских сертификатов. Вы можете найти их в списке параметров всех установленных ролей.

**Задача.** Чтобы отобразить параметры ролей,

1. на сервере с установленной ролью Deployer выполните команду:
   ```bash
   deployer params get
   ```

В полученном списке параметров требуется найти разделы с заголовком `UserDefined` для каждой роли. Файлы с расширениями `.key`, `.pem` или `.crt` в этих разделах — это файлы пользовательских сертификатов.

> [!note] Примечание
> Список параметров роли может не содержать файлов пользовательских сертификатов, если пользовательские сертификаты для нее не создавались.

Сервер, на котором сохранен сертификат, указан в начале каждого списка параметров в строке вида: `<Название роли> (<Название роли> <Версия системы>) on <Название сервера> params`.

Путь к найденным файлам сертификатов указан в подразделе `InstanceDefined` в значении параметра `CertificatesDir` каждой роли, для которой был добавлен сертификат: `CertificatesDir=/var/lib/deployed-roles/<Идентификатор приложения>/<Название экземпляра роли>/certs`.
