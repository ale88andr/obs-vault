# Экспорт конфигурационных параметров ролей в файл

Вы можете экспортировать конфигурационные параметры ролей MaxPatrol VM в файл манифеста с помощью утилиты Export-Configuration, поставляемой с ролью Deployer. Полученный в результате экспорта манифест вы можете использовать при развертывании MaxPatrol VM на другом сервере.

**Задача.** Чтобы экспортировать конфигурационные параметры ролей в файл:

1. Запустите утилиту Export-Configuration:
   ```
   /opt/deployer/bin/Export-Configuration.ps1
   ```
2. В открывшемся окне выберите варианты с идентификаторами приложений.
3. В открывшемся окне выберите экземпляры ролей, для которых необходимо экспортировать конфигурационные параметры.
   → Начнется экспорт параметров выбранных экземпляров ролей. В каталоге с утилитой появится файл `export_manifest.yaml`.
   > [!note] Примечание
   > Если в каталоге уже существует файл с именем `export_manifest.yaml`, в конец его имени будут добавлены дата и время создания нового файла: `export_manifest.yaml.<yyyyMMddHHmmss>`. Новый файл будет сохранен с именем `export_manifest.yaml`.

> Параметры роли экспортированы.

При запуске утилиты вы можете также использовать специальные ключи:

- для указания приложения — ключ `AppInstanceId <Идентификатор приложения>`. Например: `/opt/deployer/bin/Export-Configuration.ps1 -AppInstanceId mc-application`

  > [!note] Примечание
  > После запуска утилиты с этим ключом в файл манифеста будут экспортированы конфигурационные параметры всех ролей приложения, указанного в ключе.
- для указания роли — ключ `RoleInstanceId <Идентификатор экземпляра роли>`. Например: `/opt/deployer/bin/Export-Configuration.ps1 -RoleInstanceId managementandconfiguration`

Для каждого ключа можно указать только один идентификатор.
