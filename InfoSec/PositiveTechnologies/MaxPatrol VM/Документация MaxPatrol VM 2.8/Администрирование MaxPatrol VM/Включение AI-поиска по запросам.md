**Задача.** Чтобы включить AI-поиск по PDQL-запросам,

1. измените конфигурацию роли Core, указав для параметра `Text2PdqlEnabled` значение `True`.

Подробности об этой возможности см. в разделе «[[Фильтрация активов с помощью AI-поиска по запросам]]» Руководства оператора.
