# Удаление неиспользуемых пакетов ролей

Вы можете удалить неиспользуемые пакеты ролей компонентов MaxPatrol VM с помощью утилиты deployer, которая поставляется с ролью Deployer. Запускать утилиту в интерфейсе терминала необходимо с правами суперпользователя (root) на сервере с установленной ролью Deployer.

> [!note] Примечание
> Утилита запускается автоматически после установки или обновления роли, а в низконагруженных системах — после автоматического развертывания конфигурации. Если в хранилище есть неиспользуемые пакеты, вам будет предложено подтвердить их удаление.

Вы можете удалить неиспользуемые пакеты всех ролей сразу или пакеты одной роли.

**Задача.** Чтобы удалить неиспользуемые пакеты всех ролей:

1. Выполните команду:
   ```bash
   deployer package clean
   ```
2. Выберите пакеты для удаления и нажмите **Confirm**.

**Задача.** Чтобы удалить неиспользуемые пакеты одной роли:

1. Выполните команду:
   ```bash
   deployer package clean -type <Тип роли>
   ```
   → Например:
   ```bash
   deployer package clean -type SqlStorage
   ```
2. Выберите пакеты для удаления и нажмите **Confirm**.
