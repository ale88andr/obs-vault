# Количество активов: условия и ограничения лицензионного контроля

Для каждой лицензии MaxPatrol VM действует ограничение на количество активов. Лицензируемым считается актив, который был просканирован хотя бы одним из модулей: [Audit](https://help.ptsecurity.com/ru-RU/projects/vm/2.8/help/2181295371), [Pentest](https://help.ptsecurity.com/ru-RU/projects/vm/2.8/help/2181364363) или [WebEngine](https://help.ptsecurity.com/ru-RU/projects/vm/2.8/help/6069747723). Актив исключается из списка для лицензионного учета после того, как он пропадает из интерфейса системы.

Допустимое превышение — 10% количества активов, установленного для лицензии. Если ограничение будет превышено больше допустимого уровня, система сообщит об этом с помощью уведомлений. Ограничение функций системы при этом не применяется. Обратитесь к вашему менеджеру для обсуждения лицензионного контроля.
