В MaxPatrol VM реализован сбор метрик производительности СУБД. Собранные данные выводятся на виджеты дашборда в веб-интерфейсе Grafana. Дашборд содержит следующие виджеты:

- **Databases.** Виджет отображает общие данные о базах данных:

- **count** — количество баз данных в СУБД;
- **size** — общий размер всех баз данных;
- **temp bytes** — объем временных файлов, создаваемых СУБД для обработки запросов.

- **commit** — количество успешных транзакций;
- **rollback** — количество отмененных транзакций.

- **timed** — записи по расписанию;
- **req** — записи вне очереди.

- **return** — запрошенные у СУБД записи;
- **fetch** — записи, возвращаемые СУБД в результате применения фильтров;
- **insert** — вставленные записи;
- **delete** — удаленные записи;
- **update** — измененные записи.

- **PostgreSQL settings: size.** Виджет отображает заданные для роли SqlStorage параметры:

- **effective_cache_size** — объем дискового кэша на узле, на котором развернута СУБД. Параметр влияет на работу планировщика запросов;
- **shared_buffers** — объем буферного кэша, с помощью которого СУБД обрабатывает запросы;
- **wal_buffers** — объем кэша, выделенного под журнал предзаписи;
- **work_mem** — объем кэша, выделенного под запросы пользователя.

- **PostgreSQL settings: limits.** Виджет отображает заданные для роли SqlStorage лимиты:

- **autovacuum_analyze_threshold** — количество изменений строк, после которого запускается операция `autovacuum_analyze`;
- **max_connections** — максимальное количество установленных соединений;
- **max_parallel_workers**— максимальное количество параллельных вычислений для выполнения одного запроса.

- **PostgreSQL settings: time.** Виджет отображает заданное для роли SqlStorage время:

- **autovacuum_naptime** — интервал между операциями `autovacuum`. Параметр задает время, которое должно пройти между двумя операциями `autovacuum`, даже если лимит изменений строк превышен;
- **checkpoint_timeout**— интервал между записями по расписанию.

- **Database size.** Виджет отображает семь самых объемных баз данных:

- **max** — наибольший размер базы данных с момента перезапуска СУБД;
- **current** — текущий размер базы данных. Показатель может быть меньше максимального после выполнения операции `vacuum_full`.

- **idle** — установленные неактивные соединения;
- **active** — установленные активные соединения;
- **wait** — установленные активные соединения, ожидающие в очереди;
- **total backends** — все установленные соединения.
