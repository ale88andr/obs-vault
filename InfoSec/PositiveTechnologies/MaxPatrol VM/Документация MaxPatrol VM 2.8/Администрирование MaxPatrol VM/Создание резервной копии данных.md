# Создание резервной копии данных

Если вы используете пользовательские доверенные сертификаты, перед созданием резервной копии необходимо сохранить:

- копии файлов корневых и промежуточных пользовательских сертификатов центра сертификации для роли Deployer, расположенных в каталогах `/opt/deployer/pki/` и `/opt/deployer/pki/trusted_ca/`;
- копии файлов пользовательских сертификатов для остальных ролей из каталогов `/var/lib/deployed-roles/<Идентификатор приложения>/<Название экземпляра роли>/certs`;
- пути к каталогам, в которых хранятся файлы сертификатов.

> [!note] Примечание
> Вы можете получить список каталогов, в которых хранятся сертификаты, с помощью команды `deployer params get | grep CertificatesDir | uniq`.

В ходе [[Восстановление данных компонентов MaxPatrol VM на Linux из резервной копии|восстановления данных из резервной копии]] необходимо добавить:

- файлы сертификатов роли Deployer — в каталоги `/opt/deployer/pki/` и `/opt/deployer/pki/trusted_ca/`;
- файлы сертификатов остальных ролей — в каталоги `/var/lib/deployed-roles/<Идентификатор приложения>/<Название экземпляра роли>/certs`.

Чтобы избежать ошибок в ходе восстановления данных из резервной копии, при сохранении копий файлов пользовательских доверенных сертификатов их необходимо отличать от системных. Для этого вы можете воспользоваться [[Расположение пользовательских сертификатов|поиском пользовательских сертификатов]].

> [!warning] Внимание
> Перед созданием резервной копии рекомендуется сохранить каталог `/var/lib/deployer/app_packages` с пакетами приложений MaxPatrol VM. После восстановления данных роли Deployer необходимо скопировать его по прежнему пути.

Перед созданием резервной копии данных роли необходимо остановить все задачи на сбор данных, а также убедиться, что на период создания резервной копии не запланирован запуск задач по расписанию.

> [!warning] Внимание
> Во время создания резервной копии SSH-соединение не должно прерываться. В случае завершения соединения сценарий завершится ошибкой.

**Задача.** Чтобы создать резервную копию данных,

1. запустите сценарий резервного копирования:
   ```
   /var/lib/deployed-roles/<Идентификатор приложения>/<Название экземпляра роли>/backup.sh <Путь к каталогу для резервной копии>
   ```
   → Например:
   ```
   /var/lib/deployed-roles/mc-application/sqlstorage/backup.sh /home
   ```
   → По завершении сценария в консоли отобразится сообщение `Done`. Архив `backup.tar` с резервной копией будет сохранен в каталоге `/<Путь к каталогу для резервной копии>/<Идентификатор приложения>/<Название экземпляра роли>/`.
   → Например:
   → `/home/mc-application/sqlstorage`.
