**Задача.** Чтобы создать правило:

1. В главном меню выберите **Система** → **Политики**.
2. Нажмите **Создать правило**.
3. Введите название правила.
4. Выберите активы, для которых необходимо указывать сроки актуальности данных.
   > [!note] Примечание
   > Вы можете указать группы активов и отфильтровать активы с помощью PDQL-запроса. По ссылке **Вставить условие** доступны стандартные фильтры.
5. Нажмите **Сохранить**.

> Правило создано. Система начнет использовать его только [после применения изменений в политике](https://help.ptsecurity.com/ru-RU/projects/vm/2.8/help/2265453579).
