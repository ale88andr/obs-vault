Основными показателями обработки активов являются длина очереди, время ожидания в очереди и средняя скорость обработки активов. Для тонкой настройки мониторинга обработки вы можете изменять пороговые значения длины очереди и времени ожидания, а также период вычисления средней скорости обработки активов для каждой стадии обработки. Эти параметры находятся в файлах `/var/lib/deployed-roles/mp10-application/core-*/images/<Название службы>/config/custom.env` и приведены в таблице. Для реконфигурации всех ролей необходимо выполнить команду `deployer instance reconfigure -type Core`.

> [!note] Примечание
> В файле `/var/lib/deployed-roles/mp10-application/core-*/images/core.tables.extended/config/custom.env` нет значений по умолчанию. Вы можете добавить их самостоятельно.
