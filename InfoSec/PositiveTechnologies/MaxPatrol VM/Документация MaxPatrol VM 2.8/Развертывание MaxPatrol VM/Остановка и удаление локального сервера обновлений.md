# Остановка и удаление локального сервера обновлений

**Задача.** Чтобы остановить сервис получения обновлений,

1. выполните команды:
   ```bash
   sudo systemctl stop pt-update-mirror-update.timer
   sudo systemctl disable pt-update-mirror-update.timer
   ```

**Задача.** Чтобы удалить локальный сервер обновлений,

1. выполните команду:
   ```
   dpkg --purge pt-update-mirror
   ```
   > [!warning] Внимание
   > Если в конфигурационный файл вносились изменения, перед выполнением команды сохраните его копию. После выполнения команды конфигурационный файл будет удален.
