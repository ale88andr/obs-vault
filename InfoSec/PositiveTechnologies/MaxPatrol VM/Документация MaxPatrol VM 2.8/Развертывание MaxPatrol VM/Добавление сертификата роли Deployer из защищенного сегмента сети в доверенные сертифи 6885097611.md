После установки дополнительных экземпляров роли Deployer необходимо добавить сертификаты этих экземпляров в доверенные сертификаты основного экземпляра роли Deployer.

**Задача.** Чтобы добавить сертификат:

1. Скопируйте сгенерированный при установке дополнительного экземпляра роли Deployer файл сертификата `rootCA.crt` из каталога `/opt/deployer/pki/` в каталог `/opt/deployer/pki/trusted_ca` пользователя основного экземпляра роли Deployer.
2. Переименуйте скопированный файл сертификата. Например, в `rootCA-DMZ.crt`.
3. Убедитесь, что сертификат `rootCA-DMZ.crt` добавился в `/opt/deployer/pki/CAbundle.crt` и в `/usr/local/share/cacertificates`.
4. На сервере с основным экземпляром роли Deployer выполните команду:
   ```bash
   deployer instance reconfigure -RoleTypeId RmqMessageBus
   ```
5. Скопируйте сгенерированный при установке основного экземпляра роли Deployer файл сертификата `rootCA.crt` из каталога `/opt/deployer/pki/` в каталог `/opt/deployer/pki/trusted_ca` пользователя дополнительного экземпляра роли Deployer.
6. Переименуйте скопированный файл сертификата. Например, в `rootCA-Main.crt`.
7. На сервере с дополнительным экземпляром роли Deployer выполните команду:
   ```bash
   deployer instance reconfigure -RoleTypeId Deployer
   deployer instance reconfigure -RoleTypeId RmqMessageBus
   ```
