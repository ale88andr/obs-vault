> [!warning] Внимание
> Компонент PT UCS и роль Deployer необходимо устанавливать на один сервер.

Если MaxPatrol VM установлен в закрытом сегменте сети, из [[Архитектура MaxPatrol VM|функций компонента]] будут доступны только проверка наличия, загрузка и установка новых версий модуля Pentest для коллекторов с локального сервера обновлений. Для использования этих функций необходимо до установки PT UCS создать файл `/etc/salt/master.d/ucs_user.conf` со следующим содержимым:

```
updater:
  frontend_update_server:
    host: <Адрес локального сервера обновлений>:<Порт для подключения по протоколу HTTPS>
```

По умолчанию локальный сервер обновлений использует для подключения по протоколу HTTPS порт 8743.

Для доступа ко всем функциям PT UCS в закрытом сегменте сети в ходе установки или изменения конфигурации роли PT UCS вы можете настроить параметры прокси-сервера для получения обновлений через глобальный сервер обновлений.

Для проверки подлинности при передаче данных по протоколу HTTPS необходимо выпустить [[Настройка автоматического переноса обновлений в закрытый сегмент сети|сертификат SSL]]. Для корректной работы сертификата необходимо назвать файл сертификата `cert.crt`, а файл его ключа `cert.key` — и поместить эти файлы в каталог `/etc/pt-update-mirror/https_certs/` на локальном сервере обновлений. Затем необходимо перезапустить сервис с помощью команды `sudo systemctl restart pt-update-mirror.service`.

**Задача.** Чтобы установить компонент PT UCS:

1. На сервере с установленной ролью Deployer распакуйте архив `pt_ucs_<Номер версии MaxPatrol VM>.tar.gz`:
   ```
   tar -xf pt_ucs_<Номер версии MaxPatrol VM>.tar.gz -C <Путь к каталогу для распаковки архива>
   ```
2. Запустите сценарий:
   ```xml
   <Путь к каталогу для распаковки архива>/pt_ucs_<Номер версии MaxPatrol VM>/install.sh
   ```
3. Нажмите **Yes**.
4. Выберите вариант c идентификатором приложения MaxPatrol 10.
5. Выберите вариант **Deploy New Instance**.
6. Ознакомьтесь с условиями лицензионного соглашения и нажмите **I Accept**, чтобы принять их.
7. Выберите вариант с доменным именем сервера роли Deployer.
8. Введите название экземпляра роли UCS и нажмите **ОК**.
9. Если MaxPatrol VM установлен в закрытом сегменте сети и для соединения с глобальным сервером обновлений планируется использовать прокси-сервер, выберите **Advanced configuration**.
   > [!note] Примечание
   > Настройка параметров прокси-сервера позволит получать обновление данных для компонента PT Feeds и загружать дистрибутивы с новыми версиями компонентов MaxPatrol VM.
10. Установите флажок **ProxyEnabled**.
11. Укажите значения параметров:
    ```
    ProxyAddress: <IP-адрес или FQDN прокси-сервера>
    ProxyPassword: <Пароль служебной учетной записи для подключения к прокси-серверу PT UCS>
    ProxyPort: <Порт прокси-сервера для входящего подключения от PT UCS>
    ProxyUser: <Логин служебной учетной записи для подключения PT UCS к прокси-серверу>
    ```
12. Нажмите **ОК**.
    → Начнется проверка сервера на соответствие программным и аппаратным требованиям.
    → Если сервер не соответствует требованиям, отобразится сообщение `Warning` или `Error`. Описание параметров и ошибок приведено в разделе «[[О проверке серверов перед установкой ролей|О проверке сервера перед установкой роли]]».
    > [!note] Примечание
    > Если в результате проверки отобразилось сообщение `Warning`, вы все равно можете продолжить установку, нажав `Continue`. Чтобы включить режим установки, при котором сообщения `Warning` будут автоматически игнорироваться, необходимо использовать ключ `--silent` при запуске сценария `install.sh`.
    → Начнется установка пакетов. По завершении установки появится сообщение `Deployment configuration successfully applied`.
13. Нажмите **ОК**.
14. Если требуется подтвердить изменение конфигурации ролей, параметры которых связаны с изменяемой ролью, нажмите **Confirm**.
15. Если подключение через прокси-сервер будет осуществляться по протоколу HTTP, создайте файл `/etc/salt/master.d/user_ucs_params.conf` со следующим содержимым:
    ```
    updater:
    frontend_update_server:
    proxy: 'http://<Адрес прокси-сервера>:<Порт для подключения по протоколу HTTP>'
    ```

По завершении установки компонент PT UCS готов к работе, его настройка не требуется. Проверка наличия новых версий модуля Pentest для коллекторов, а также их загрузка и установка будут происходить автоматически.

В результате установки роли в каталоге, из которого был запущен сценарий `install.sh`, формируется каталог `installReports` с отчетами об установке. В случае ошибки установки каталог с отчетами будет создан в каталоге `<Идентификатор приложения роли>_<Номер версии>`. Отчеты сохраняются в HTML-файлах и содержат информацию о системе и журналы установки. Вы можете передавать отчеты в рамках запроса в техническую поддержку для анализа проблем.
