Для работы MaxPatrol VM необходимо активировать лицензию.

Перед активацией лицензии MaxPatrol VM необходимо установить и активировать PT MC. Активация лицензии MaxPatrol VM выполняется в интерфейсе PT MC. Для активации необходима учетная запись с ролью администратора.

Активация лицензии MaxPatrol VM состоит из следующих этапов:

1. Добавление в PT MC лицензии продукта.

   > [!note] Примечание
   > При первой активации PT MC приобретенные лицензии добавляются автоматически. Если вы устанавливаете экземпляр MaxPatrol VM, который интегрирован с уже действующим компонентом PT MC, нужно добавить лицензию MaxPatrol VM по инструкции.
2. Привязка лицензии к приложению MaxPatrol VM.

Информация о лицензии доступна в интерфейсе PT MC на странице **Лицензии**.

## Добавление лицензии

**Задача.** Чтобы добавить лицензию при наличии доступа к интернету:

1. В главном меню выберите **Лицензии**.
2. Нажмите **Обновить список лицензий**.

Для добавления лицензии вручную вам потребуется ZIP-файл с лицензией из комплекта поставки.

> [!note] Примечание
> Если ваш комплект не содержит ZIP-файла с лицензией, вы можете запросить его в службе технической поддержки.

**Задача.** Чтобы добавить лицензию вручную, без доступа к интернету:

1. В главном меню выберите **Лицензии**.
2. Нажмите **Добавить**.
3. Выберите ZIP-файл с лицензией.
   > [!note] Примечание
   > Файл может содержать как одну, так и несколько лицензий. В систему будут добавлены все корректные лицензии, которые содержатся в файле.
4. Нажмите **Добавить**.

Теперь вы можете привязать лицензию к приложению.

## Привязка лицензии

**Задача.** Чтобы привязать лицензию к приложению:

1. В главном меню выберите **Лицензии**.
2. Выберите лицензию и нажмите **Привязать**.
3. Выберите установленное приложение, к которому нужно привязать лицензию.
4. Нажмите **Привязать**.

После привязки лицензии необходимо перезапустить службу компонента MP 10 Core с помощью команды `docker restart $(docker ps -q -a)`, а затем выйти из системы и заново войти.

Теперь вам доступны функции приложения, которые включены в лицензию.
