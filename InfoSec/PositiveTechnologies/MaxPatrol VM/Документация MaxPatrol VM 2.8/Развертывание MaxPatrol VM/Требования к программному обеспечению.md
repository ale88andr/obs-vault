Все компоненты MaxPatrol VM поддерживают установку на 64-разрядные версии следующих ОС:

- Astra Linux Special Edition 1.7.5 и 1.7.6 в режиме защищенности «Воронеж» (на базе ядра Linux версии 5.15 и выше);
- Debian 10.3 и выше;
- Debian 11 и 12 (на базе ядра Linux версии 5.10 и выше).

Кроме того, вы можете установить компонент MP 10 Collector на Microsoft Windows Server 2012, 2012 R2, 2016, 2019 и 2022.

Для работы в интерфейсе MaxPatrol VM рекомендуется использовать последние версии браузеров Google Chrome, Mozilla Firefox, Microsoft Edge или Яндекс Браузер.

Корректная работа серверов MaxPatrol VM под управлением Astra Linux Special Edition уровня защищенности «Воронеж» подтверждена при использовании значений функций безопасности Astra Linux по умолчанию:

- «Режим МКЦ» — активирован мандатный контроль целостности (далее МКЦ);
- «Блокировка ptrace» — включен запрет трассировки и отладки выполнения программного кода;
- «sudo с паролем» — включен обязательный ввод пароля при использовании механизма sudo.

Включение других функций безопасности может ограничить работоспособность продукта. Список функций безопасности Astra Linux приведен [в справочном центре Astra Linux](https://wiki.astralinux.ru/).

> [!note] Примечание
> Проверить состояние функций безопасности Astra Linux вы можете с помощью команды `astra-security-monitor`.
