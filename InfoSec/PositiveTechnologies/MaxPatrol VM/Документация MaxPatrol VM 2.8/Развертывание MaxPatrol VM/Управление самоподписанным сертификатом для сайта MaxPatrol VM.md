# Управление самоподписанным сертификатом для сайта MaxPatrol VM

При развертывании MaxPatrol VM для его сайта автоматически устанавливается самоподписанный сертификат, поставляемый в составе дистрибутива. Если вы используете самоподписанный сертификат, при попытке подключения к сайту вы получите предупреждение о том, что создаваемое подключение не защищено.

После развертывания MaxPatrol VM самоподписанный сертификат `rootCA.crt` и его закрытый ключ `rootCA.key` находятся в каталоге `/opt/deployer/pki/`.

Срок действия сертификата составляет пять лет. Автоматическое обновление сертификата не предусмотрено: по истечении срока действия установка TLS-соединений с использованием этого сертификата станет невозможной.

**Задача.** Чтобы проверить срок действия сертификата,

1. выполните команду:
   ```bash
   openssl x509 -in /opt/deployer/pki/rootCA.crt -noout -dates
   ```
   → На экран будут выведены даты начала и окончания срока действия сертификата.
   → Например:
   ```
   notBefore=Mar 23 15:34:35 2026 GMT
   notAfter=Mar 22 15:34:35 2031 GMT
   ```

**Задача.** Чтобы получить полную информацию о сертификате,

1. выполните команду:
   ```bash
   openssl x509 -in /opt/deployer/pki/rootCA.crt -noout -text
   ```
   → На экран будет выведена информация о версии и серийном номере сертификата, алгоритм его подписи, сведения об издателе и владельце, параметры ключа, срок действия, расширения и цифровая подпись сертификата.

## Выпуск нового сертификата

Вы можете выпустить новый сертификат с пятилетним сроком действия.

> [!warning] Внимание
> Выпуск нового сертификата рекомендуется запланировать в период технического обслуживания, так как во время изменения конфигурации экземпляров ролей возможны сбои TLS-соединений между службами MaxPatrol VM.

**Задача.** Чтобы выпустить новый сертификат:

1. Удалите сертификат `rootCA.crt` и его закрытый ключ `rootCA.key` из каталога `/opt/deployer/pki/`.
2. Выполните команду для изменения конфигурации роли Deployer:
   ```bash
   deployer instance reconfigure -type Deployer
   ```
3. Выполните команду для изменения конфигурации всех экземпляров установленных ролей:
   ```bash
   deployer instance reconfigure
   ```

В результате изменения конфигурации роли Deployer будет выпущен новый сертификат, а после изменения конфигурации всех экземпляров информация о новом сертификате будет распространена между всеми компонентами системы.
