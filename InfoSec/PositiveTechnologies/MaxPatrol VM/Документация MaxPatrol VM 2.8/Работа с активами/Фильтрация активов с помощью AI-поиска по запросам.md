> [!warning] Внимание
> Эта возможность находится на стадии бета-тестирования. После включения AI-поиска MaxPatrol VM требует дополнительно 2 ГБ оперативной памяти. Чтобы включить эту возможность, нужно изменить конфигурацию роли Core.

С помощью AI-поиска вы можете вызывать готовые PDQL-запросы, вводя на странице **Активы** фразы на русском или английском языках. Доступны PDQL-запросы для поиска активов и уязвимостей, а также для проверки соответствия стандартам.

**Задача.** Чтобы искать активы и уязвимости с помощью AI-поиска:

1. В главном меню выберите **Активы**.
2. Нажмите ![[7192866699.png]].
3. Введите в поле поиска запрос на русском или английском языке.
   → Например:
   ```
   все уязвимости
   ```
4. Выберите один из вариантов поиска в списке. Например, **Уязвимости ПО** или **Уязвимости ОС**.

Подробности о включении этой возможности см. [[Включение AI-поиска по запросам|в Руководстве администратора]].
