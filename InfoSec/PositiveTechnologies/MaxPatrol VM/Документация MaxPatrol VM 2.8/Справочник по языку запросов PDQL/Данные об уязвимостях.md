# Данные об уязвимостях

В MaxPatrol VM для актива могут быть указаны уязвимости. Уязвимостям ПО присваивается идентификатор в соответствии с классификацией уязвимостей Common Vulnerabilities and Exposures (CVE). Веб-уязвимости не имеют идентификатора CVE, но их можно различать по идентификаторам паспортов уязвимостей, на основе которых они зарегистрированы.

Идентификатор уязвимости может быть использован при формировании условия фильтрации активов на языке PDQL.

> [!note] Примечание
> Идентификатор уязвимости может быть указан в условии фильтрации на языке PDQL в любом регистре.

Кроме того, фильтрация и настройка представления данных об активах и уязвимостях на этих активах могут осуществляться с помощью [[Псевдонимы уязвимостей|псевдонимов для полей уязвимости]].
