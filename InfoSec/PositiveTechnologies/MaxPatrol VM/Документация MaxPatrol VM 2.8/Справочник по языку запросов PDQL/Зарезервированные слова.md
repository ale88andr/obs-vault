Некоторые слова в языке PDQL зарезервированы для служебных нужд, их нельзя переопределить и использовать в качестве пользовательских идентификаторов.

В PDQL используются следующие зарезервированные слова.

> [!note] Примечание
> Все зарезервированные слова являются регистронезависимыми.

**Зарезервированные слова**

| Слово | Описание |
| --- | --- |
| `as` | Псевдоним колонки |
| `asc, desc` | Направление сортировки: по возрастанию, по убыванию |
| `and, or, not, in, match, like, <, <=, >,>=, contains, intersect` | Обозначение операторов |
| `max, min, avg, sum, count, countunique, compact, compactunique` | Обозначение функций агрегации |
| `true, false` | Значения атрибутов Булева типа |
| `null` | Отсутствие значения |
| `qsearch, select, filter, sort, limit, unique, group, join, calc` | Обозначение операций |
| `now` | Обозначение функции, которая возвращает текущее время |
| `upper, lower` | Обозначение функций приведения к верхнему и нижнему регистру |
| `ceil` | Обозначение функции, которая возвращает наименьшее целое число, большеe или равноe входному параметру `field` |
| `totaldays, totalhours, totalminutes, totalseconds` | Обозначение функций вычисления длительности временных промежутков |
| `if, then, else` | Слова для условного оператора |
| `median` | Слово зарезервировано для использования в следующих версиях языка PDQL |
