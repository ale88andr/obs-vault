В MaxPatrol VM реализована модель активов: все собранные сведения об активах представлены в виде объектов. С помощью набора этих объектов может быть охарактеризован любой актив. Объекты модели имеют атрибуты, которые могут быть использованы при формировании условия фильтрации активов на языке PDQL.

Все атрибуты объектов модели активов регистронезависимы, то есть при обработке PDQL-запроса система игнорирует регистр символов.

> [!warning] Внимание
> При интеграции с другими системами, импортирующими данные из MaxPatrol VM, следует перед импортом предусмотреть приведение строковых символов к единому регистру. Импорт данных об активах, не приведенных к единому регистру, может вызвать ошибки и некорректную работу интеграций.

## Обращение к атрибутам

Атрибуты вызываются в запросе в зависимости от их уровня вложенности. Разные уровни вложенности разделяются точкой:

- **Примитивный тип данных.** У объекта Host есть атрибут FQDN, который является строкой. Для обращения к этому атрибуту нужно использовать `Host.FQDN`. Пример запроса: `Select(@Host, Host.FQDN)`
- **Непримитивный тип данных.** У объекта Host также есть атрибут Endpoints, который содержит коллекцию объектов типа Network.Endpoint. У каждого объекта Network.Endpoint есть атрибут URI, который является строкой. Чтобы обратиться к этому атрибуту, нужно использовать `Host.Endpoints.Uri`. Пример запроса: `Select(@Host, Host.Endpoints.Uri)`

Атрибуты, связанные с псевдонимами, обозначаются как `@Alias`, где Alias — это имя псевдонима.

**Атрибуты модели активов для типа Host**

| Атрибут | Описание | Пример запроса |
| --- | --- | --- |
| Host.OsName | ОС актива | `Select(@Host,Host.OsName)` |
| Host.OsVersion | Версия ОС актива | `Select(@Host,Host.OsVersion)` |
| Host.Softs | ПО, установленное на активе | `Select(@Host,Host.Softs)` |
| Host.Softs.Name | Название ПО, установленного на активе | `Select(@Host,Host.Softs.Name)` |
| Host.Softs.Vendor | Вендор ПО, установленного на активе | `Select(@Host,Host.Softs.Vendor)` |
| Host.Softs.Version | Версия ПО, установленного на активе | `Select(@Host,Host.Softs.Version)` |
| Host.Softs.InstallPath | Путь установки ПО, установленного на активе | `Select(@Host,Host.Softs.InstallPath)` |
| Host.Softs.Architecture | Архитектура ПО, установленного на активе | `Select(@Host,Host.Softs.Architecture)` |
| Host.Softs.OsFamily | Семейство ОС программного обеспечения, установленного на активе | `Select(@Host,Host.Softs.OsFamily)` |
| Host.Softs.OpenPorts | Открытые порты ПО, установленного на активе | `Select(@Host,Host.Softs.OpenPorts)` |
| Host.Softs.UninstallKey | Ключ удаления ПО, установленного на активе | `Select(@Host,Host.Softs.UninstallKey)` |
| Host.Endpoints | Конечные точки, открытые на активе | `Select(@Host,Host.Endpoints)` |
| Host.Endpoints<TransportEndpoint> | Конечные точки уровня L4 (транспортного уровня), открытые на активе | `Select(@Host,Host.Endpoints<TransportEndpoint>)` |
| Host.Endpoints<TransportEndpoint>.Port | Порт конечной точки уровня L4 (транспортного уровня) | `Select(@Host,Host.Endpoints<TransportEndpoint>.Port)` |
| Host.Endpoints<TransportEndpoint>.Protocol | Протокол конечной точки уровня L4 (транспортного уровня) | `Select(@Host,Host.Endpoints<TransportEndpoint>.Protocol)` |

В предикатах, которые обращаются к полному наименованию типа актива в модели (псевдоним @FullType), необходимо использовать двоеточия вместо точек, например `WindowsHost.Softs<Software:Kaspersky:KasperskySecurityCenter>.Plugins`.
