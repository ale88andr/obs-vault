РЕГЛАМЕНТ КОНТРОЛЯ ЗАЩИЩЕННОСТИ ЛВС ПФР 1. Общие сведения 1.1. Цели и задачи. Целью данного документа является описание порядка взаимодействия под- разделений ПФР в рамках промышленной эксплуатации программного комплекса контроля защищенности сети «MaxPatrol» (далее ПККЗС «MaxPatrol»). 1.2. Настоящий Регламент разработан с учетом требований руководящих документов: 1.2.1. Распоряжение Правления ПФР от 30, 12.2011 518p «Об организации опытной эксплуатации программного комплекса контроля защищенности сети «МахРаи•о1». 1.2.2. Распоряжение Правления ПФР от 24.07.2012 .ћГ2 204р «Об организации системы контроля защищенности вычислительных сетей». 1.2.3. «Программный комплекс контроля защищенности сети. Установка и настройка программного комплекса контроля защищенности сети в системе ПФР. Инструкция», утвержденная б декабря 2011 года заместителем Председателя Правления ПФР Н.В. Елистратовым. 1.3. Сфера действия регламента. 1.3.1. Настоящий Регламент распространяется на работы, связанные с кон- тролем защищенности автоматизированной информационной системы ПФР. 1.3.2. Настоящий Регламент определяет порядок действий Департамента по обеспечению информационной безопасности (далее — Департамент), подразделе- ний по защите информации ОПФР. Далее по тексту взаимодействие с подразде- 2 лениями по защите информации ОПФР и управлением информационных техноло- гий ОПФР, Межрегионального информационного центра (далее — МИЦ). А. Обеспечение обновления регламента. Поддержание настоящего Регламента в актуальном состоянии обеспечива- ется Департаментом. 2. Порядок эксплуатации ПККЗС «MaxPatrol» 2.1. Сканирование сегментов АИС ПФР для обнаружения уязвимостей про- изводится ежемесячно. 2.2. Департамент выполняет следующие функции: 2.2.1. Координирует деятельность подразделений по защите информации ОПФР, МИЦ и управления информационных технологий ОПФР по проведению сканирования и устранению уязвимостей. 2.2.2. Готовит консолидированный отчет об уязвимостях в АИС ПФР-2. 2.2.3. Анализирует консолидированный отчет и при необходимости оказы- вает методическую помощь подразделениям по защите информации и подразде- лениям информационных технологий ОПФР, МИЦ. 2.3. Вносит изменения в настоящий Регламент на основании опыта про- мышленной эксплуатации и доводит их до сведения ОПФР, МИЦ. 2.4. Подразделение по защите информации ОПФР выполняет следующие функции: 2.4.1. Устанавливает и настраивает в ОПФР программный комплекс кон- троля защищенности сети. Установка и настройка программного обеспечения осуществляется в соответствии с утвержденной инструкцией (п. 1.2.3) и дополне- нием по результатам опытной эксплуатации (Приложение N22). 2.4.2. Проводит сканирование сегмента АИС ПФР-2, эксплуатируемого в ОПФР, для обнаружения уязвимостей. 2.4.3. Контролирует результаты устранения уязвимостей подразделением информационных технологий ОПФР. з 2.4.4. Доводит до подразделения информационных технологий методиче- ские рекомендации по устранению уязвимостей и изменения настоящего Регла- мента. 2.4.5. Устранение уязвимостей обеспечивается подразделением информаци- онных технологий ОПФР . 2.5. Обмен документами осуществляется по корпоративной электронной почте. З. Подразделение по защите информации ОПФР помечает узлы, по ко- торым принято положительное решение об исключении, в списке узлов сканиро- вания (в поле «Признак включения в список сканирования» заносится значение «О», в поле «Дата исключения» заносится дата проведения мероприятия, а в поле «Обоснование исключения» - описание причины исключения). Актуальный спи- сок узлов сканирования направляется в подразделение информационных техноло- гий ОПФР для сведения и в Управление по защите информации для контроля. 3.2.2. Департамент может запросить в подразделении по защите информа- ции ОПФР дополнительные сведения обоснования исключения узлов из списка сканирования. 3.3. Департамент выборочно проверяет списки узлов сканирования для кон- троля обоснованности прекращения сканирования узлов сегментов АИС ПФР-2. 4 4. Порядок обнаружения и устранения уязвимостей 4.1.
