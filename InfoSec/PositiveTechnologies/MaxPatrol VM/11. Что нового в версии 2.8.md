# Что нового в версии 2.8

> [!abstract] Источник
> [[Что нового в версии 2.8]] — полный текст раздела документации.
> См. также: [[План изучения]], [[Документация]].

Краткая выжимка изменений MaxPatrol VM 2.8 по категориям документации: новые возможности, улучшения, расширение покрытия экспертизы и технические особенности обновления.

## Новые возможности

**Лицензионный контроль количества активов.** При превышении лимита активов, установленного для лицензии, MaxPatrol VM отображает предупреждение.

**Стандартная роль «Наблюдатель».** Новая стандартная роль в MaxPatrol 10 только с правами на просмотр данных — для гибкого разграничения доступа по полномочиям сотрудников. Подробнее о стандартных ролях — в разделе «Предоставление прав доступа» документации и в [[6. Автоматизация и политики]].

**Совместимость с FreeIPA и ALD Pro.** Подключение к службам каталогов FreeIPA и ALD Pro по LDAP: синхронизация и аутентификация пользователей, сопоставление групп каталога с ролями MaxPatrol VM.

**Персональные токены доступа.** В PT MC можно создавать бессрочные персональные токены для запросов к API, требующим авторизации. Подробнее — «Управление токенами доступа» Руководства администратора PT MC; об использовании API см. [[9. REST API и интеграции]].

**Парольная политика и блокировка пользователей.** В веб-интерфейсе PT MC, раздел **Параметры приложений**: сложность пароля, срок его действия, количество попыток ввода, время неактивности до блокировки. В карточке заблокированного пользователя теперь отображается причина блокировки.

**Новая роль «Оператор» в Management and Configuration.** Стандартная роль, позволяющая просматривать всю информацию в приложении.

## Улучшения

- **Подробное журналирование действий** — журнал показывает не только факт изменений, но и что именно изменено: смена паролей и ролей, изменение набора привилегий роли.
- **PDF-отчёты до 5000 страниц** (увеличен допустимый объём).
- **XLSX-отчёты по шаблонам на 30% быстрее.**
- **Деактивация PT MC в веб-интерфейсе** — на странице **Лицензии**, например при восстановлении из резервной копии на другом устройстве ([[Деактивация PT MC|Деактивация]]).
- **Активные ссылки в журнале действий пользователя** — панель **Подробности** содержит ссылку на страницу расширенной информации (например, на отчёт), открывается в новой вкладке.
- **FQDN как цель HostDiscovery** — сбор полных доменных имён из целей сканирования снижает дублирование активов при сканировании в разных режимах.
- **Ротация результатов сканирования, импорта и ручного ввода активов** — автоудаление данных по достижении срока хранения освобождает диск и актуализирует состояние активов на основе событий ([[Ротация результатов сканирования, импорта и ручного ввода активов|Ротация результатов]]).
- **Новые возможности утилиты deployer** (роль Deployer): установка любого параметра экземпляра роли, сброс параметров к значениям по умолчанию, получение списка параметров с описанием и типами, удаление неиспользуемых пакетов ролей компонентов.

## Экспертиза: поддержка систем и стандартов

**Обнаружение систем** (режим Audit): HashiCorp Vault, Secret Net Studio, Veritas InfoScale, Zabbix Agent 2, ОС «ОСнова».

**Сбор данных о конфигурации:** Apache HTTP Server, Elasticsearch, Eltex ESR, Eltex MES (под управлением ISS), Eltex MES 5448, Juniper Networks Junos OS, Kaspersky Security Center, Microsoft IIS, Microsoft Office, Microsoft SharePoint, nginx, Proxmox VE.

**Обнаружение уязвимостей:** Apache Cassandra, Atlassian Bamboo, Atlassian Bitbucket, HashiCorp Consul, IBM AIX, Jenkins, Kubernetes, macOS, OpenNebula, pgAdmin, PowerDNS Recursor, PowerDNS Authoritative Server, Teleport, VMware Workstation, zVirt, ОС «ОСнова».

Полный перечень поддерживаемых систем — в разделе «Что можно сканировать и аудировать» ([[3. Сбор данных и сканирование]]).

## Технические особенности

- Версия 2.8 поддерживает обновление с версий **2.0, 2.1, 2.5, 2.6, 2.7**.
- Перед обновлением рекомендуется **остановить все задачи на сбор данных** и убедиться, что на период обновления не запланирован запуск задач по расписанию — иначе накапливаются очереди и возможны ошибки после обновления.
