# Уязвимости и патч-менеджмент

Устранение «потенциальных целей атак» — первая линия из [[KSC Защита]] («Устанавливайте обновления безопасности для ОС и программ»). KSC умеет делать это централизованно.

## Что умеет KSC

1. **Инвентаризация ПО** — что установлено на управляемых компьютерах (задача «Инвентаризация», см. [[KSC Защита]], раздел 5.3).
2. **Оценка уязвимостей** — сопоставление установленного ПО с базой уязвимостей; результат виден в отчёте и в выборке устройств.
3. **Установка обновлений Windows** — одобренные обновления распространяются как обычные пакеты (задача «Установка обновлений» по умолчанию есть на устройствах — [[KSC]]).
4. **Обновления стороннего ПО** — патчи для сторонних приложений через правила одобрения обновлений.

## Порядок внедрения

1. Включить инвентаризацию на репрезентативных машинах (не на всех сразу — нагрузка на сеть и БД, см. [[KSC Защита]] 5.3).
2. Запустить оценку уязвимостей, сформировать первичный отчёт: топ уязвимых продуктов в парке.
3. Настроить **правила одобрения обновлений**: критичные — автоматически, остальные — вручную после теста.
4. Создать групповые задачи установки обновлений для групп администрирования.
5. Ежемесячно: повторная оценка → дельта-отчёт → цикл повторяется.

## Ограничения

- На KSCLinux функциональность сторонних обновлений и поиска уязвимостей ограничена (таблица сравнения в [[Развертывание Kaspersky Security Center]]) — для Linux-парка патчить средствами дистрибутива (`apt`/`yum`) и контролировать отдельно.
- Точность оценки зависит от полноты инвентаризации: софт, собранный не полностью, = слепые зоны.

> [!warning] Диск сервера при Patch Management
> Загруженные патчи оседают в хранилище сервера и могут забить диск — проверять свободное место регулярно ([[Рекомендации по ежедневному администрированию Kaspersky Security Center]]).

## Регламент

| Периодичность | Действие |
| --- | --- |
| Еженедельно | Просмотр отчёта по уязвимостям на критичных узлах |
| Ежемесячно | Полная оценка + установка одобренных обновлений |
| Ежеквартально | Пересмотр правил одобрения, чистка хранилища патчей |
