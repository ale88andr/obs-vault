# Глоссарий Kaspersky

Термины, разбросанные по конспектам, собраны в одном месте. Подробный контекст — по ссылкам.

## Защита и обнаружение

- **Сигнатура** — запись в «стоп-листе» известных вредоносных файлов; идентифицирует семейство угроз ([[Как Kaspersky Endpoint Security проверяет файлы]]).
- **Эвристический анализ** — запуск файла в изолированной среде (эмуляция выполнения) для ловли полиморфных угроз.
- **Полиморфизм / метаморфизм** — техники смены собственного кода вредоносом для ухода от сигнатур ([[0. Antivirus]]).
- **KSN** — облачная репутация файлов/URL/издателей; вердикт KSN приоритетнее локальной сигнатуры. Ответы кэшируются локально.
- **BSS (шаблоны опасного поведения)** — то, с чем сравнивает журнал действий Анализ поведения.
- **AMSI** — механизм Windows, через который KES перехватывает вредоносные скрипты.
- **NDIS-фильтр** — драйверный уровень перехвата сетевого трафика KES ([[KSC Защита]], 4.1).
- **klif.sys** — драйвер Защиты от файловых угроз, перехватывающий файловые операции.

## Компоненты и задачи

- **Защита от файловых угроз** vs **Поиск вирусов** — первая проверяет на лету при обращении, вторая — по расписанию/запросу; дополняют друг друга ([[KSC Защита]], 3.5).
- **Scan_IdleScan (Фоновая проверка)** — локальная задача проверки при простое; заменила автоматическую задачу быстрого поиска вирусов начиная с KSC 10 ([[KSC]], [[KSC Обслуживание]]).
- **Резервное хранилище** — зашифрованные копии обработанных объектов до лечения/удаления; источник восстановления при ложных срабатываниях.
- **Лечение активного заражения** — агрессивная процедура против работающего в памяти вредоноса; блокирует запуск программ, требует подтверждения/опции в задаче ([[Рекомендации по ежедневному администрированию Kaspersky Security Center]]).
- **Счетчик вирусов** — счётчик детектов на компьютере; сбрасывается вручную («Обнулить счетчик вирусов»).

## Инфраструктура

- **Шлюз соединений** — агент администрирования в особом режиме: туннелирует подключения других агентов к серверу через своё соединение (практика — [[Цифровая зона]]).
- **Точка распространения** — узел, разгружающий сервер: развёртывание, обновления, синхронизация внутри сегмента.
- **Автономная политика (для автономных пользователей)** — политика для машин вне корпоративной сети; наследуется только целиком ([[KSC Защита]], 7.2).
- **Замок политики** — закрытый замок делает настройку обязательной и неизменяемой вниз по иерархии ([[2. Настройка политик]]).
- **Нераспределённые устройства** — найденные в сети компьютеры вне групп администрирования; управляются номинально, не фактически ([[KSC]]).

## Индикаторы

- **IoC / IoA / TTP** — пирамида боли: хеши/IP (часы) → последовательности действий (недели) → тактики противника (годы). Подробно — [[0. Antivirus]].

> [!tip] Пополнять по мере появления новых терминов в конспектах, а не заводить отдельные заметки-определения.
