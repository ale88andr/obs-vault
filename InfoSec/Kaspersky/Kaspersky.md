# Kaspersky — главная страница

База знаний по продуктам «Лаборатории Касперского»: теория антивирусной защиты, развёртывание и ежедневное администрирование **Kaspersky Security Center (KSC)**, настройка **KES** (Windows) и **KESL** (Linux), а также инфраструктурные решения («Цифровая зона», требования НСД).

> [!tip] Как пользоваться
> Новичкам — идти по учебной серии сверху вниз. Опытным администраторам — разделы «Управление защитой» и «Быстрая справка». Конкретные how-to — в соответствующих тематических блоках.

## Учебная серия «Антивирус»

Теория → архитектура → развертывание → политики → контроль:

1. [[0. Antivirus]] — классы ВПО, векторы доставки, методы выявления, технологии Kaspersky (KSN, System Watcher, AEP), IoC/IoA/TTP, AV vs EDR, эволюция AV→NGAV→EDR→XDR→MDR.
2. [[0. Архитектура]] — компоненты KSC и их роли; порты сервера администрирования и агента; результат стандартной установки (службы, пути, учётные записи).
3. [[1. Удаленное развертывание защиты]] — способы установки Network Agent (агент / средства ОС по SMB+RPC / точки распространения); план внедрения из 12 шагов.
4. [[2. Настройка политик]] — замки и наследование политик; карта компонентов KES против типов атак; исключения и маски; почему KES не замедляет ПК; сетевой экран и защита от сетевых угроз.
5. [[3. Контроль]] — Контроль программ, Контроль устройств, Веб-контроль.

## Kaspersky Security Center — практика

- [[KSC]] — справочник: компоненты, службы, порты, ключи vs коды активации, стандартные задачи, три способа опроса сети, инсталляционные пакеты, линейка EPP (KESS / KSWS).
- [[Развертывание Kaspersky Security Center]] — установка KSC на Astra Linux: репозиторий astra-ce → PostgreSQL 14 → postinstall.pl → Web Console (файл ответов) → сравнение Linux vs Windows.
- [[Установка klnagent]] — подготовка Astra Linux к удаленной установке агента (PATH, logind.conf, sudoers), проверка портов через `nc`.
- [[Пример политики KSC]] — визуальная инструкция по настройке политики (скриншоты всех вкладок).
- [[Рекомендации по ежедневному администрированию Kaspersky Security Center]] — операционный runbook: отчёты и виджеты, статусы защиты, klnagchk / klmover, лицензии и резервные ключи, чеклисты (периодический + инцидент), лечение активного заражения.
- [[Ошибка - Содержимое не готово]] — фикс ошибки хранилища обновлений: очистка → перезапуск kladminserver → повторная загрузка задачей.

## Управление защитой

- [[KSC Защита]] — ядро базы знаний: пути проникновения ВПО и контрмеры; настройка файловой / почтовой / веб-защиты; SSL-инспекция; продвинутая защита (Анализ поведения, Предотвращение вторжений, эксплойты, Откат); пакетные правила сетевого экрана; автономные политики; самозащита и парольная защита.
- [[KSC Контроль программ]] — запрещающий vs разрешающий режим контроля запуска программ.
- [[KSC Обслуживание]] — регламент поддержки по периодам (день / неделя / месяц / квартал / год), реагирование на заражение, резервное копирование (klbackup), обслуживание БД.
- [[Как Kaspersky Endpoint Security проверяет файлы]] — разбор klif.sys: сигнатуры, эмуляция, кэш ответов KSN.

## KESL (Endpoint Security для Linux)

- [[Обновление KESL]] — перевод задачи Update (№6) на локальный источник `/var/update` (offline-обновление).
- [[KESL Настройка Kaspersky Endpoint Security]] — антивирусные исключения для OpenStack / Kubernetes / СУБД + таблицы настроек политик.
- [[Установка KESL]] — ссылки на официальную документацию по установке и типовым ошибкам.

## Экосистема и интеграции

- [[Экосистема Kaspersky]] — лестница продуктов KES → EDR → XDR → KATA → KUMA → MDR: что добавляет каждый уровень и когда пора переходить дальше.
- [[Защита виртуализации]] — агент в ВМ vs Light Agent vs agentless; практика для OpenStack/k8s (почему только полный агент и как не поймать AV-шторм).
- [[Интеграция KSC с SIEM]] — выгрузка событий в CEF/LEEF по syslog, минимальный набор критичных событий, проверка контура.

## Инфраструктура и регламенты

- [[Цифровая зона]] — схема DMZ-узла с тремя интерфейсами, правила UFW, транзит через Континент 4.1.7, шлюз соединений Network Agent, установка агента по scp.
- [[Требования по защите от НСД]] — организационно-технические меры для Windows при работе с СКЗИ КриптоПро (реестровые твики, права доступа).
- [[Сертифицированные исполнения]] — исполнения ФСТЭК/ФСБ, реестр российского ПО, правила обновлений без выхода из сертифицированного состояния.
