Относится к HW (аппаратные платформы) и VA (виртуальная платформа).

## Общие положения

- Инициализация выполняется при **первом включении устройства** или после сброса настроек. В ходе неё устанавливается **дистрибутив ключей `ds5`** — файл, содержащий справочники, ключи и лицензии, необходимые для инициализации и работы HW5 (в HW5 **только `ds5`**; формат `dst` используется в HW 4.4.x, xFirewall и Client).
- Дистрибутив `ds5` формируется в **ViPNet Prime** на основе заданных связей между узлами.
- Для входа в мастер инициализации используются учётные данные по умолчанию: имя пользователя **`user`, пароль `user`**.
- На шаге 16 сценария задаётся пароль локального администратора **`admin`** — именно он используется для входа в устройство после инициализации.

## Способы установки дистрибутива ключей

| Способ | Как подключаются | Где лежит файл `ds5` |
| --- | --- | --- |
| С внешнего устройства (USB/CD) | HW: монитор + клавиатура (VGA/PS/2) или компьютер через консольный порт; VA: консоль платформы виртуализации | USB-носитель (ФС **FAT32, ext2, ext3, ext4**) или CD-диск, подключённые к устройству |
| По протоколу TFTP | Компьютер подключается **напрямую к интерфейсу `eth1`** кабелем RJ45 Cat. 5 (у VA — средствами платформы виртуализации) | Папка на компьютере, подключённом к `eth1` |

### Требования к установке по TFTP (подготовка компьютера)

- На компьютере должны быть включены службы: **Telnet или SSH** (подключение к устройству) и **TFTP-клиент** (перенос файла). В Windows по умолчанию отключены — включаются через «Компоненты Windows» (TFTP Client, Simple TCPIP services).
- На время установки: **отключить компьютер от внешней сети**, отключить защиту ViPNet Client (если установлен), Windows Firewall, Defender, Windows Update.
- Установить на сетевом интерфейсе компьютера IP-адрес **`169.254.241.5`**.
- Подключиться к устройству по адресу **`169.254.241.1`** (PuTTY: тип терминала VT100+, кодировка **KOI8-R**, terminal type `linux`, ширина окна 120).

## Сценарий инициализации (консольный режим, 40 шагов)

1. Включить устройство.
2. Войти: пользователь **`user` / пароль `user`**.
3. Выбрать консольный режим мастера установки — ввести `1`.
4. Принять условия лицензионного соглашения.
5. Начать установку — подтвердить `y` (установка ключей или восстановление конфигурации из бэкапа).
6–10. Задать последовательно: **континент (или UTC) → страну → часовой пояс → подтверждение → дату/время** (формат `YYYY-MM-DD hh:mm:ss`, при необходимости).
11. Выбрать способ установки дистрибутива: `t` (TFTP), `u` (USB), `c` (CD).
12–13.
- Для **TFTP** — на компьютере выполнить: `tftp -i 169.254.241.1 put <имя_файла_дистрибутива_ключей>`.
- Для **USB/CD** — найти файлы `ds5`; если их несколько — выбрать нужный по имени/идентификатору узла (список показывает, какому узлу сети соответствует файл); если файлов нет — мастер вернёт к шагу 11.
14. Ввести **пароль к файлу дистрибутива ключей** (`Enter password`).
15. Выбрать ручной способ настройки (`Select the setup method` → `1`).
16. **Задать пароль локального администратора `admin`**.
17. При аутентификации пользователей по сертификату — инициализировать **USB-токен admin**: издать сертификат и закрытый ключ, задать ПИН администратора и ПИН пользователя токена.
18–20. **Настроить сетевые интерфейсы последовательно, начиная с `eth0`**: включить интерфейс (`y`), выбрать режим DHCP или статической адресации, при статике ввести IP-адрес и маску. Ограничения: запрещены `0.0.0.0`, маски `0.0.0.0` / `255.255.255.254` / `255.255.255.255`; для разных интерфейсов нельзя задавать адреса одной подсети.
21. Если ни на одном интерфейсе нет DHCP — задать **шлюз по умолчанию**.
22–25. Настроить режимы автозапуска **DNS-сервера** и **NTP-сервера**, при необходимости добавить свои DNS/NTP-серверы (по умолчанию — корневые DNS и публичные NTP-серверы).
26. Имя компьютера (по умолчанию формируется по шаблону `<исполнение>-<идентификатор узла>`, например `HW1000-270E033A`).
27. Диапазон **виртуальных IP-адресов** (по умолчанию `11.0.0.1–11.255.255.254`, CIDR `11.0.0.1/8`), при пересечении с реальной адресацией — изменить (диапазон или нотация CIDR).
28–30. Проверка связи с узлом сети ViPNet (`probe VPN-connection`): задать режим подключения к внешней сети — **со статической трансляцией адресов (Static NAT)** или **с динамической (Dynamic NAT)**; можно отказаться и использовать настройки из дистрибутива.
31. При статической трансляции: номер **UDP-порта** (по умолчанию **55777**; если несколько координаторов за одним NAT — порты должны различаться) и выбор внешнего интерфейса.
32. При динамической трансляции: выбрать координатор, через который устройство подключается к сети (в списке — только координаторы со связями в справочниках устанавливаемого дистрибутива), при необходимости задать его IP-адрес; затем выбрать внешний интерфейс.
33–36. Выбрать узел для проверки связи, при необходимости задать его IP-адрес вручную, запустить проверку. При успехе все настройки сохраняются в **`iplir.conf`**.
37–38. При неудаче — просмотреть журнал IP-пакетов (`view IP packet log`) для выяснения причины; затем либо перенастроить проверку (Ctrl+C), либо продолжить.
39. Запустить драйверы и службы VPN перед завершением мастера (`start VPN services`).
40. Завершить инициализацию — `ViPNet Coordinator HW successfully deployed!` → Enter.

## Полноэкранный режим

Порядок шагов идентичен консольному (ввод `2` вместо `1` на шаге 3), отличие — только в форме ввода (окна мастера с кнопками Next/Yes/Finish вместо текстовых строк). Завершение: `Setup wizard is successfully completed` → **Finish**.

## После инициализации (обязательные шаги в CLI)

1. Подключиться по командному интерпретатору, войти под `admin`, перейти в режим настройки (`enable`).
2. **Выяснить IP-адрес доступа к ViPNet Prime**: `iplir node <ViPNet ID ViPNet Prime> show`.
3. **Добавить запись в hosts** (IP Prime и его доменное имя):

```text
hostname# machine hosts add <IP-адрес доступа к ViPNet Prime> <доменное имя ViPNet Prime>
```

4. **Проверить маршрут по умолчанию**: `inet show routing` — при отсутствии задать статический маршрут по умолчанию и убедиться, что он валиден.
5. **Разрешить SSH-доступ** (по умолчанию заблокирован) — фильтр защищённой сети:

```text
hostname# firewall vpn add rule "Allow SSH server" src <ViPNet ID узла | группа> dst @local service @ssh pass
```

6. **Разрешить доступ к веб-интерфейсу** (по умолчанию заблокирован, HTTPS, TCP-порт 8080):

```text
hostname# firewall vpn add rule "Allow ViPNet WebGUI" src <ViPNet ID узла | группа> dst @local tcp dport 8080 pass
```

7. При необходимости **разблокировать учётную запись аудитора `user`**: `user passwd`.
8. Если в сети есть координаторы версий ниже 4.5.1 — настроить транспортные серверы MFTP.

## Ключевые параметры для запоминания

- Доступ в мастер: `user` / `user`; после шага 16 — `admin` / заданный пароль.
- Виртуальные адреса по умолчанию: `11.0.0.0/8`; UDP-порт обмена: `55777`.
- TFTP-адреса: компьютер `169.254.241.5` → устройство `169.254.241.1` (интерфейс `eth1`).
- Конфигурация инициализации сохраняется в `iplir.conf`; после неё устройство подключается к **Prime** через транспортный клиент **UT** (приём сообщений UT с обновлениями справочников, ключей и политик).
- Перед инициализацией необходимо иметь подготовленный в Prime дистрибутив `ds5` и его пароль.
