**Nmap Cheat Sheet: сканирование портов, определение служб и NSE**
Команды Nmap для обнаружения хостов, сканирования портов, определения служб, NSE-скриптов, управления таймингом, вариаций пакетов и экспорта результатов сканирования.

**Сканирование Nmap — Cheat Sheet**

**Что такое Nmap?**
Nmap картографирует сетевую доступность, находя достижимые хосты, прослушиваемые порты и службы за ними. Тип сканирования, тайминг и скрипты должны соответствовать вопросу, на который нужно ответить.

**Ping-сканирование (ping sweep) — обнаружение живых хостов без сканирования портов**
```
nmap -sn 192.168.1.0/24
```
Ping-сканирование ICMP echo, timestamp и netmask
```
nmap -sn -PE -PP -PM 192.168.1.0/24
```
Пропустить обнаружение хостов — считать цель онлайн (полезно, когда ICMP заблокирован)
```
nmap -Pn 10.10.10.10
```
TCP SYN ping на определённых портах
```
nmap -PS22,80,443 192.168.1.0/24
```
TCP ACK ping — хорошо подходит для обхода stateful-фаерволов
```
nmap -PA80,443 192.168.1.0/24
```
Ping-сканирование с использованием конкретного DNS-сервера
```
nmap -sn --dns-servers 8.8.8.8 192.168.1.0/24
```
SYN-сканирование (stealth) — по умолчанию при запуске от root, полуоткрытое соединение
```
nmap -sS 10.10.10.10
```
TCP connect-сканирование — полное соединение, root не требуется
```
nmap -sT 10.10.10.10
```
UDP-сканирование распространённых портов (DNS, SNMP, IKE)
```
nmap -sU -p 53,161,500 10.10.10.10
```
ACK-сканирование — карта правил фаервола, определение filtered vs unfiltered
```
nmap -sA 10.10.10.10
```
Сканирование всех 65535 портов
```
nmap -p- 10.10.10.10
```
Сканирование конкретных портов
```
nmap -p 22,80,443,8080,8443 10.10.10.10
```
Сканирование топ-100 самых распространённых портов
```
nmap --top-ports 100 10.10.10.10
```
Null-сканирование — флаги не установлены, может обойти некоторые фаерволы
```
nmap -sN 10.10.10.10
```
FIN-сканирование — только флаг FIN, может обойти stateless-фильтры пакетов
```
nmap -sF 10.10.10.10
```
Xmas-сканирование — установлены флаги FIN, PSH, URG
```
nmap -sX 10.10.10.10
```
Определение служб/версий на открытых портах
```
nmap -sV 10.10.10.10
```
Агрессивное определение версий (шкала 0–9, выше = больше проб)
```
nmap -sV --version-intensity 9 10.10.10.10
```
Определение ОС (требуется root)
```
nmap -O 10.10.10.10
```
Агрессивное сканирование: ОС, версии, скрипты, traceroute (-O -sV -sC --traceroute)
```
nmap -A 10.10.10.10
```
Версия служб + NSE-скрипты по умолчанию
```
nmap -sV -sC 10.10.10.10
```
Запустить все скрипты обнаружения уязвимостей
```
nmap --script vuln 10.10.10.10
```
Запустить набор скриптов по умолчанию (то же, что -sC)
```
nmap --script default 10.10.10.10
```
Запустить только безопасные скрипты — минимальное воздействие на цель
```
nmap --script safe 10.10.10.10
```
Проверка учётных данных по умолчанию/слабых паролей в различных службах
```
nmap --script auth 10.10.10.10
```
Перечисление каталогов и файлов веб-сервера
```
nmap --script http-enum 10.10.10.10
```
Проверка на EternalBlue (MS17-010) — уязвимость WannaCry
```
nmap --script smb-vuln-ms17-010 -p 445 10.10.10.10
```
Проверка на уязвимость Heartbleed
```
nmap --script ssl-heartbleed -p 443 10.10.10.10
```
Получение HTTP-заголовков страниц по подсети
```
nmap --script=http-title -p 80,443,8080,8443 192.168.1.0/24
```
Paranoid — очень медленно, обход IDS
```
nmap -T0 10.10.10.10
```
Sneaky — медленно, обход IDS
```
nmap -T1 10.10.10.10
```
Normal — тайминг по умолчанию
```
nmap -T3 10.10.10.10
```
Aggressive — быстро, предполагает надёжную сеть
```
nmap -T4 10.10.10.10
```
Insane — очень быстро, может пропускать порты в ненадёжных сетях
```
nmap -T5 10.10.10.10
```
Минимум 1000 пакетов/сек — быстрое полное сканирование портов
```
nmap --min-rate 1000 -p- 10.10.10.10
```
Decoy-сканирование — 10 случайных приманок маскируют реальный IP сканера
```
nmap -D RND:10 10.10.10.10
```
Decoy-сканирование с конкретными IP-приманками
```
nmap -D 192.168.1.100,192.168.1.101,ME 10.10.10.10
```
Фрагментация пакетов — может обойти простые фильтры пакетов
```
nmap -f 10.10.10.10
```
Подмена исходного порта 53 (DNS) — может обойти фаерволы, пропускающие DNS-трафик
```
nmap --source-port 53 10.10.10.10
```
Рандомизация порядка сканирования хостов — снижает вероятность обнаружения по сигнатурам
```
nmap --randomize-hosts 192.168.1.0/24
```
Idle/zombie-сканирование — полностью слепое, использует IP зомби-хоста
```
nmap -sI zombie_host 10.10.10.10
```
Обычный вывод в файл
```
nmap -oN output.txt 10.10.10.10
```
XML-вывод (разбирается Metasploit и др.)
```
nmap -oX output.xml 10.10.10.10
```
Grepable-вывод
```
nmap -oG output.gnmap 10.10.10.10
```
Все форматы одновременно (.nmap, .xml, .gnmap)
```
nmap -oA output 10.10.10.10
```
Подробный вывод — прогресс в реальном времени
```
nmap -v 10.10.10.10
```
